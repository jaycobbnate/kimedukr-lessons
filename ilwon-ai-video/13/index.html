1학습 목표 설명

  • 영상 두 개를 위아래로 겹치면 위 영상이 아래를 가린다는 원리를 설명할 수 있다.

  • 음성 분리·음성 변조기로 소리의 원리를 체험하고, 노이즈 제거·음성 보정·노멀라이즈·쉼 삭제로 목소리를 다듬을 수 있다.
  • 자동 캡션을 만들고 오타를 고친 뒤, 배경 있는 자막으로 원래 자막을 덮고 펀치 줌과 스티커로 마무리할 수 있다.

STEP 1 · 이론

겹치기 · 마스크 · 키프레임의 원리

오늘 만드는 손가락 창, 창 안 효과, 장면 펼치기는 모두 세 가지 재료의 조합입니다. 이 원리를 알면 SNS에서 본 유행 효과를 스스로 따라 만들 수 있습니다.

1세 가지 재료 설명

2겹치기: 트랙 순서가 곧 앞뒤 순서 설명

STEP 2 · 작품 ①

손가락 창 만들기

엄지와 검지로 만든 네모 창이 움직일 때, 그 창 안에만 효과나 다른 영상이 보이게 합니다. 실습 A는 같은 영상 두 개로 창 안에만 효과, 실습 B는 창 안에 다른 영상 + 창 밖 흑백입니다.

1완성 모습과 구조 설명

2내 손을 직접 찍는다면 설명 선택

  • 휴대폰을 삼각대나 컵에 기대 고정하고 찍기 (화면이 흔들리면 창 맞추기가 훨씬 어려움)
  • 배경은 단색 벽이나 어두운 천
  • 엄지·검지로 네모를 만들고 천천히 키웠다 줄였다, 옮겼다
  • 5~6초면 충분합니다
연습은 짧게강사 손 영상은 34초입니다. 34초를 다 하면 키프레임이 수십 개라, 연습은 5~6초 구간만 잘라서 해요.

3따라 하기 ① 손 영상 준비 실행 필수

  1. 강사 손 영상을 아직 안 받았으면 → ⬇ 강사 손 영상 받기
  2. 새 프로젝트 → 손 영상 가져오기 → 타임라인에 놓기
  3. 가운데 세부 정보 → 수정하기 → 가로 세로 비율: 강사 손 영상은 1:1, 휴대폰으로 세워 찍었으면 9:16 → 저장
  4. 강사 손 영상만: 손 영상 클립 선택 → 오른쪽 동영상 → 기본 → 확대에 185 입력 → 사방의 검은 띠가 사라지고 손이 화면에 꽉 참 (직접 찍은 영상은 건너뛰기)
  5. 재생 헤드 13초에 두고 Q(왼쪽 삭제) → 다시 6초쯤에 두고 W(오른쪽 삭제)

강사 손 영상은 13초부터 손가락 창이 또렷하게 움직입니다. 아래 숫자 표도 이 자리 기준입니다.

4실습 A · 창 안에만 효과 넣기 실행 필수

  1. 손 영상 클립 선택 → Ctrl+C → Ctrl+V → 복사본을 바로 위 트랙, 같은 시작 자리로 끌어 맞추기
  2. 위 클립 선택 → 창 안에 넣을 효과 고르기 (아래 표에서 하나)
  3. 위 클립 선택 → 동영상 → 마스크 → 마스크 추가(+) → 직사각형
  4. 재생 헤드 0초 → 화면의 네모 틀을 끌어서 손가락 끝 4개의 안쪽에 맞추기 (모서리 점 = 크기, 안쪽 = 위치, 아래 ↻ = 회전)
  5. 마스크 설정 줄 오른쪽 ◇ 누르기 → 첫 키프레임 ◆
  6. 재생 헤드 1초 뒤 → 틀을 다시 손가락 끝 안쪽에 맞추기 (키프레임 자동 추가)
  7. 구간이 끝날 때까지 반복 → 재생해서 어긋난 곳에 하나 더
창 안에 넣을 효과하는 법
흑백 Free위 클립 → 조정 → 기본 → 채도 막대 끝까지 왼쪽 (-50)
반짝이위쪽 효과 탭 → 검색 「반짝」 또는 「glitter」 → 마음에 드는 효과를 위 클립 위로 끌어다 놓기
색 바꾸기위 클립 → 필터 하나 적용, 또는 조정에서 색온도·색조
흐림위쪽 효과 탭 → 검색 「흐림」 또는 「blur」 → 위 클립 위로 끌기
효과는 꼭 클립 위로 끌어다 놓기효과를 빈 트랙에 놓으면 아래 영상까지 전부 효과가 걸려서 창 안팎 차이가 없어집니다. 효과 이름 옆 💎가 있으면 프로 기능입니다. 효과 이름은 버전에 따라 다르니 검색어로 찾아보세요.

5효과 여러 개를 바꿔 가며 움직이기 실행 선택

  1. 실습 A를 끝까지 한 상태에서, 재생 헤드를 2초에 두고 위 클립만 선택 → Ctrl+B(분할)
  2. 4초에서도 한 번 더 분할 → 위 클립이 세 조각
  3. 조각마다 효과를 다르게: 둘째 조각은 효과를 지우고 채도 -50, 셋째 조각은 흐림
  4. 재생해서 창이 움직이는 동안 효과가 바뀌는지 확인
다른 방법: 효과 위에 효과 겹치기한 조각에 효과를 두 개 넣으면 섞여서 보입니다. 예: 반짝이 + 채도 -50 = 흑백 위에 반짝이.

6펜 마스크로 손가락 모양 그대로 실행 💎 선택

  1. 위 클립 → 동영상 → 마스크 → 펜
  2. 손가락 끝 4곳에 점을 하나씩 찍어 닫기
  3. 마스크 설정 ◇로 키프레임 → 재생 헤드를 옮기고 점 위치를 다시 맞추기를 몇 프레임마다 반복
미리 한 번 해 보세요펜 마스크 점을 옮길 때 키프레임이 자동으로 찍히는지는 캡컷 버전에 따라 다를 수 있습니다. 점을 옮긴 뒤 타임라인에 ◆가 생기는지 확인하고, 안 생기면 마스크 설정의 ◇를 직접 눌러 주세요.

7실습 B · 창 안에 다른 영상 + 창 밖 흑백 실행 필수

  1. 새 프로젝트에 손 영상을 실습 A ①처럼 준비 (1:1 · 확대 185 · 13초에서 자르기)
  2. 뚜비(또는 내 영상)를 손 영상 위 트랙, 0초부터 끌어다 놓기
  3. 내 영상이 화면을 다 채우지 못하고 위아래에 검은 띠가 보이면 → 위 클립 동영상 → 기본 → 확대를 띠가 없어질 때까지 키우기 (가로 영상이면 180 정도)
  4. 위 클립에 직사각형 마스크 → 실습 A와 똑같이 키프레임으로 손가락 따라가기
  5. 아래 손 영상 선택 → 조정 → 기본 → 채도 막대를 끝까지 왼쪽 (-50)
채도는 아래 손 영상만!위 클립까지 바꾸면 창 안도 흑백이 돼요.

8한 걸음 더 선택

둥근 모서리·회전직사각형 마스크 설정 아래쪽 둥근 모서리, 위쪽 회전도 키프레임이 돼요. 손이 기울면 회전도 같이 맞춰 보세요.
원형 마스크로 반짝이 스포트라이트손 영상 대신 아무 영상(뚜비)으로 실습 A를 하되 마스크를 원형으로, 페더를 크게 올리고, 키프레임으로 원이 화면 왼쪽 → 오른쪽으로 지나가게 해 보세요. 반짝이는 조명이 훑고 지나가는 느낌이 납니다.
릴스 원본 버전 (얼굴 앞 손가락)내 얼굴 앞에서 손가락 창을 찍기 → 클립 복사해 위 트랙에 → 위 클립에 마스크 → 아래 원본에만 편집효과(효과를 아래 클립 위로 끌어다 놓기). 창 안은 원래 얼굴, 창 밖은 효과가 돼요.

2실습 A · 노래에서 목소리와 반주 나누기 실행 Free 필수

1소리 다듬기 순서 설명

①~③은 소리만 바뀌고 길이는 그대로, ④는 영상 길이가 줄어듭니다. 그래서 ④까지 끝낸 다음 STEP 6에서 자막을 만듭니다.

2세로 프로젝트 만들기 실행 필수

  1. 홈 → 프로젝트 만들기
  2. 가져오기 → 민원 해결(고객 불만 해결 스토리) 영상 넣기
  3. 영상을 타임라인으로 끌어 놓기 → 화면이 자동으로 세로(9:16)로 바뀌는지 확인
막힐 때: 화면이 가로로 나와요미리보기 오른쪽 아래 비율 버튼에서 9:16을 고르세요.

3노이즈 제거 → 음성 보정 → 노멀라이즈 실행 💎 ×3 필수

  1. 곰 영상 클립 누르기 → 오른쪽 오디오 탭
  2. 노이즈 제거 체크
  3. 음성 보정 체크 → 「처리 중」이 끝나면 아래 강도 막대 확인 (처음 값 75)
  4. 음향 노멀라이즈 체크
  5. 체크를 켰다 껐다 하며 들어 보고 비교

음성 보정을 켜면 강도 막대가 나옵니다. 너무 올리면 목소리가 기계처럼 들리니 50~80 사이에서 고르세요.

4대본으로 말 사이 쉼 한 번에 자르기 실행 💎 대본 필수

  1. 곰 영상 클립을 누른 채로 타임라인 위 도구 줄의 대본 버튼 누르기 (보석 표시)
  2. 「분석 중… 채우기용 단어 인식 중」이 끝나면 채우기용 단어 삭제 창이 열림
  3. 오른쪽 탭 확인:
    • 일시 중지 — 말이 끊긴 빈 구간 (곰 영상은 0.6~0.7초짜리가 여러 개)
    • 반복 — 같은 말을 두 번 한 곳
    • 채우기용 단어 — "음", "어" 같은 말
  4. 지울 항목에 체크(줄 그은 글자) → 아래 총 길이가 줄어드는 것 확인 (31초 → 약 26초)
  5. 오른쪽 아래 삭제
너무 많이 지우면 숨이 막혀요쉼을 다 지우면 말이 숨 쉴 틈 없이 붙어서 어색할 수 있습니다. 미리보기로 들어 보고, 이상한 곳은 체크를 풀어 두세요.

STEP 6 · 작품 ②-2

곰 숏폼 ② 자막 넣고 원래 자막 덮기

곰 영상에는 자막이 이미 박혀 있습니다. 자동 캡션을 만든 뒤 배경이 있는 자막으로 원래 자막을 덮어 새 자막으로 바꾸고, 펀치 줌과 스티커로 마무리합니다.

1순서가 중요합니다 설명

2자동 캡션 만들기 실행 필수

  1. 위쪽 메뉴 캡션 → 왼쪽 자동 캡션
  2. 소스 언어 한국어 확인 (이중 언어 캡션은 「없음」 그대로)
  3. 오른쪽 아래 생성 → 「음성이 인식되었습니다」가 뜨고 영상 위에 자막 줄(TT)이 생김
왜 템플릿 대신 기본 자막인가요?캡션 템플릿(💎)으로 만든 자막은 오른쪽에 「속성」만 나오고 배경 설정이 없습니다. 원래 자막을 덮으려면 기본 자막으로 만들어야 합니다.

3오타 고치기 실행 필수

  1. 왼쪽 자막 목록에서 틀린 줄을 눌러 바로 고치기
  2. 곰 영상에서 자주 틀리는 곳: "온인을" → "원인을", "하 고객님의" → "아, 고객님의"
  3. 다 고친 뒤 처음부터 재생하며 한 번 더 확인
생성 버튼 다시 누르지 않기자동 캡션 「생성」을 다시 누르면 자막을 새로 만들어 고친 오타가 다 사라집니다.

4배경으로 원래 자막 덮기 실행 필수

  1. 자막 줄을 하나 누르기 (모든 자막에 함께 적용됨)
  2. 오른쪽 텍스트 → 기본 → 맨 아래 배경 체크
  3. 배경 색 검정, 불투명도 100%
  4. 배경 너비 100%, 필요하면 둥근 직사각형으로 모서리 둥글게
  5. 위쪽 변환에서 위치 Y -1600, 확대 130% → 원래 자막 자리로 내려가 덮임
  6. 가장 긴 문장("원인을 분석하기 시작했습니다")까지 다 가려졌는지 재생해서 확인
막힐 때
  • 숫자가 이상하게 들어가요 → 칸에 직접 치면 첫 숫자가 빠지는 일이 있습니다(-1600이 -600으로). 입력한 뒤 칸의 숫자를 꼭 다시 보세요.
  • 원래 자막 윗줄이 상자 위로 보여요 → 원래 자막이 두 줄인 곳입니다. 배경 높이를 25% 정도로 올리세요.
템플릿 자막도 덮을 수 있어요템플릿 자막은 배경이 글자 크기만큼만 생겨서 양옆으로 원래 자막이 보일 수 있습니다. 템플릿을 고른 뒤에 배경 너비만 100%로 다시 올려 주세요. 템플릿을 고르면 자막이 새로 만들어지니 템플릿 → 오타 수정 → 배경 순서로 하세요.

5"세 배 빨라졌습니다"에 펀치 줌 실행 Free 필수

펀치 줌은 강조하고 싶은 말이 나오는 순간 화면을 "쿵" 하고 확 당겨 크게 보여 주는 효과입니다. 키프레임 점 두 개를 가깝게 찍으면 됩니다.

  1. 재생 헤드를 「세 배」 말이 시작하는 곳에 두기
  2. 곰 영상 클립 → 동영상 → 기본 → 확대 옆 ◇ 눌러 키프레임 (100%)
  3. 재생 헤드를 0.3초 뒤로 → 확대를 130%로 바꾸기 (◇가 저절로 하나 더 찍힘)
  4. 재생해서 화면이 "쿵" 하고 다가오는지 확인
영상을 키우면 원래 자막도 같이 커져요영상을 130%로 키우면 박혀 있던 원래 자막도 커지고 아래로 밀려서 덮개 상자 밖으로 삐져나옵니다. 115% 정도로 약하게 하거나, 그 구간만 배경 높이를 올리세요.
막힐 때타임라인 빈 곳을 누르면 영상 조각이 모두 선택돼서 값이 「-」로 바뀝니다. 그럴 땐 Ctrl+Z로 되돌리고 조각 하나만 다시 누르세요.
한 걸음 더「48시간」에도 같은 펀치 줌을 넣고, 0.3초 뒤에 다시 100%로 돌아가게 키프레임을 하나 더 찍어 보세요.

6엄지척 장면에 스티커 실행 💎 선택

  1. 위쪽 메뉴 스티커 → 검색 좋아요 또는 thumbs up
  2. 마음에 드는 움직이는 스티커 하나를 마지막 장면 위 트랙에 끌어 놓기
  3. 곰 얼굴과 자막을 가리지 않게 크기·자리 맞추기

스티커 왼쪽 위 보석 표시가 있으면 프로 스티커입니다. 보석이 없는 스티커는 무료로 내보낼 수 있습니다.

7한 걸음 더 선택

① 캡션 템플릿 💎으로 숏폼 자막새 프로젝트에 곰 영상을 다시 넣고 → 캡션 → 템플릿 → 히트에서 디자인 고르기 → 아래 캡션 생성. 「단어」 분류는 한 단어씩 뜨는 숏폼 스타일입니다. 원래 자막과 겹치지 않게 위치를 화면 가운데쯤으로 올려 쓰세요.
② 이중 언어 캡션 💎자동 캡션 화면의 이중 언어 캡션에서 「영어」를 고르고 다시 생성하면 한국어 아래 영어 자막이 한 줄 더 붙는 기능입니다.
③ 토리 영상에 화자별 자막토리와 뚜비 대사에 자동 캡션을 만든 뒤, 토리 대사는 분홍, 뚜비 대사는 초록으로 글자 색을 다르게 바꿔 보세요.
