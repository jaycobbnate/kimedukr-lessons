오늘의 지도

내 영상의 주인공을 만들고, 그 주인공의 평범한 하루를 장면으로 옮깁니다.

핵심오늘 만드는 것

  1. 주인공 캐릭터 시트 — 정면·옆·뒤·표정이 한 장에
  2. 움직이는 프로필 영상
  3. 3장면 콘티 + 스토리보드 — 제미나이와 함께, 글 표와 그림 한 장
  4. 시작 → 끝 장면 영상 — 새 기능

준비오늘 쓰는 곳

플로우 열기 ↗ 제미나이 열기 ↗

  • 플로우는 웹(노트북)에서 — 시작·끝 프레임은 웹에서만 됩니다
  • 영상은 360p로 (크레딧 절약)
  • 만든 건 바로 다운로드

예제는 둘 중 하나, 아니면 내 이야기

예제 A 동네 카페예제 B 동네 공원내 이야기

하루 3장면가게 문 열기 → 커피 내리기 → 저녁 문 닫기집 나서기 → 공원 벤치 → 해 질 녘 귀가내 하루 세 장면

모든 프롬프트는 [빈칸]만 바꾸면 A·B·내 이야기 어느 쪽이든 그대로 작동합니다. 🟢 공통은 모두 함께, 🔵 확장은 여유 있는 분만.

2

주인공 만들기

얼굴 → 캐릭터 시트 → 저장 → 새 장면에 적용 → 움직이는 프로필. 같은 얼굴이 계속 나오게 만드는 순서입니다.

핵심같은 얼굴이 유지되는 원리

플로우는 넣어 준 재료 이미지를 보고 그 얼굴을 따라 그립니다. 얼굴 한 장만 주면 옆모습·뒷모습은 AI가 짐작해서 다른 사람이 되기 쉬워요. 여러 각도를 한 장에 모은 캐릭터 시트를 주면 어느 방향에서도 같은 사람으로 그립니다.

강사 먼저① 주인공 얼굴 만들기

🟢 이미지 만들기 · 비율 16:9.

Portrait photo, eye level, waist-up. [주인공], [나이], natural friendly expression, [옷], soft morning window light, simple background, realistic.

인물 사진, 눈높이, 상반신. [주인공], [나이], 자연스럽고 편안한 표정, [옷], 부드러운 아침 창가 빛, 단순한 배경, 사실적.

[woman / man]에서 하나, [나이]는 숫자 하나로 — 나와 비슷하게, 가족처럼, 상상 속 인물 모두 OK · 뒤 프롬프트는 전부 the person이라 성별과 상관없이 그대로 작동

강사 먼저② 캐릭터 시트 만들기

🟢 ①의 이미지를 재료로 넣고 · 비율 16:9.

Character reference sheet of the same person from the reference image: front view, side view and back view in full body, plus three face close-ups (smiling, surprised, thinking). Same outfit in every view, plain white background, clean evenly spaced layout.

재료 이미지 속 같은 사람의 캐릭터 시트: 정면·옆·뒤 전신 + 얼굴 가까이 표정 3개(웃음·놀람·생각). 모든 모습에 같은 옷, 흰 배경, 깔끔한 배치.

same outfit = 옷까지 고정 · plain white background = 재료로 쓸 때 배경이 섞이지 않게

준비③ 에셋으로 저장

  1. 시트 결과가 마음에 들면 다운로드
  2. 프로젝트 안에 남겨 두고 이름을 주인공_시트로
  3. 다음 시간에도 이 한 장으로 시작합니다

얼굴이 조금 달라진 모습이 섞여 있으면 다시 생성 — 시트가 틀리면 이후 전부 틀립니다.

장소·조명을 바꿔도 얼굴이 유지되는지 확인

주의잘 안 될 때

  • 사람이 여러 명 나옴 → only one person in the frame
  • 얼굴이 달라짐 → 시트를 재료로 다시 넣었는지 확인
  • 옷이 바뀜 → [장면]에 옷을 한 번 더: wearing the same beige apron
  • 실제 다른 사람·연예인 얼굴은 쓰지 않기
3

콘티·스토리보드

만들기 전에 장면을 먼저 설계합니다. 제미나이로 콘티(글 표)와 스토리보드(그림)를 함께 만들고, 플로우 에이전트로 한 장면을 실제 이미지로.

핵심콘티 + 스토리보드 = 한 세트 설계도

콘티는 장면마다 무엇을 어떻게 보여줄지 적은 글 표, 스토리보드는 그 장면을 칸마다 그린 그림입니다. 표로 약속하고, 그림으로 확인해요. 표의 칸 이름은 STEP 1의 카메라 말 다섯 가지 그대로라 새로 배울 말이 없습니다.

강사 먼저① 제미나이로 3장면 콘티

🟢 제미나이 열기 ↗ → 아래 문장을 붙여 넣기.

[주인공]의 평범한 하루를 3장면 영상 콘티로 짜줘. 표로 정리해줘: 장면 번호 / 무슨 일 / 얼마나 가까이(멀리·중간·가까이) / 어디서 보나(눈높이·아래서·위에서·바로 위) / 카메라 움직임(다가가기·물러나기·돌기·따라가기·가만히 중 하나) / 조명 / 플로우에 넣을 영어 프롬프트. 조건: 장면당 8초, 화면엔 주인공 한 명, 잔잔하고 따뜻한 분위기, 과장 없이.

제미나이는 한글로 물어도 됩니다. 마지막 칸에 영어 프롬프트까지 받아 두면 번역이 따로 필요 없어요.

[주인공] 예: 동네 카페를 하는 40대 여성 사장님 / 아침 산책하는 30대 남성 — 나이·성별은 내가 정한 대로

강사 먼저② 제미나이로 스토리보드 그리기

🟢 같은 제미나이 열기 ↗ 대화창에서 이어서. 주인공_시트 이미지를 첨부하고 아래 문장.

위 콘티 3장면으로 스토리보드 한 장을 그려줘. 가로로 3칸, 첨부한 캐릭터 시트의 주인공이 칸마다 한 명씩. 칸마다 콘티의 거리·방향대로 구도를 잡고, 카메라 움직임은 화살표로 표시. 연필 스케치 느낌, 흰 바탕, 포인트 색 하나. 글자는 칸 번호 1·2·3만. 가로 16:9.

글자는 번호만 — 그림 속 한글은 깨지기 쉬워요. 장면 설명은 콘티 표가 맡습니다.

스토리보드는 '예쁜 그림'이 아니라 구도 확인용 — 대충이어도 충분

준비스토리보드로 확인할 세 가지

  1. 칸마다 거리(멀리·중간·가까이)가 콘티대로인가
  2. 세 칸이 다 같은 거리면 지루해요 — 하나는 바꾸기
  3. 주인공이 같은 사람으로 보이나

마음에 안 들면 "2번 칸을 바로 위에서 본 구도로 바꿔줘"처럼 칸만 고쳐 달라고 하세요.

내 차례③ 제미나이에게 추천받기

🟢 콘티가 나오면 이어서 물어보세요.

2번 장면에 어울리는 카메라 움직임과 조명을 두 가지 추천해줘. 각각 왜 어울리는지 한 줄씩, 그리고 영어 프롬프트도.

추천을 받으면 STEP 1 추천표와 비교해 보세요. 둘이 다르면 왜 다른지 물어봐도 좋아요.

준비④ 플로우 에이전트 켜기

플로우 열기 ↗

  1. 프로젝트 안 입력창에서 Agent 누르기
  2. 옆 패널을 크게 보려면 펼치기
  3. 주인공_시트와 스토리보드를 입력창으로 끌어다 놓기

에이전트와 대화하는 건 크레딧이 들지 않아요(하루 횟수 제한은 있음). 이미지·영상을 만들면 그때 크레딧이 듭니다.

강사 먼저⑤ 스토리보드 한 칸을 실제 장면으로

🟢 에이전트 창에 한글로.

스토리보드 1번 칸의 구도대로, 캐릭터 시트의 주인공으로 사실적인 장면 이미지를 만들어줘. [콘티 1번 장면 설명]. 어울리는 조명도 추천해서 넣어줘. 화면엔 한 명만, 16:9.

스케치 → 사실적인 장면. 에이전트가 프롬프트를 짜고 생성까지 해 줍니다. 결과는 STEP 4의 시작 장면으로 씁니다.

확장🔵 더 해보기

에이전트에게 스토리보드 세 칸 모두 사실적인 장면으로 만들어 달라고 해 보세요. 세 장에서 얼굴이 같은지 나란히 비교.

플로우에서 직접 그려도 됩니다: A three-panel storyboard sheet, pencil sketch style, the same person from the character sheet in each panel, [장면 1] / [장면 2] / [장면 3], camera movement shown as arrows, panel numbers only, 16:9.

4

장면을 영상으로 — 시작·끝 프레임

새 기능: 시작 장면과 끝 장면을 정해 주면, 그 사이 움직임을 플로우가 만듭니다.

핵심시작·끝 프레임 = '이 모습이 저 모습으로'

옴니 플래시 1.1에 끝 프레임이 생겼습니다. 이미지 두 장을 시작과 끝으로 꽂으면 중간은 AI가 채워요. 문 닫힌 가게 앞 → 불 켜진 카운터, 벤치를 바라봄 → 앉아 쉬는 모습처럼 상태가 바뀌는 장면에 딱 맞습니다.
