STEP 01같이 해요

워크스페이스 · 원본

📖 무엇인가요

미리캔버스에서 만든 디자인과 복사해 온 디자인이 모두 모이는 내 보관함이에요. 여기 있는 것이 원본이고, 지우면 되살릴 수 없어요.

🙋 이럴 때 써요

  • 어제 만든 교안을 다시 열 때
  • 템플릿을 복사해 와서 고칠 때

🗺️ 한눈에 보기

1📄템플릿 복사
➜
2✏️새 디자인
➜
3🗂️워크스페이스 (원본)
➜
4📑사본에서 작업
⚠️ 주의해요 원본은 그대로 두고 사본을 만들어 연습해요

👀 살펴보기

  • 복사해 온 디자인과 새로 만든 디자인은 모두 「워크스페이스」에 저장돼요
  • 워크스페이스에 있는 것이 원본이에요
  • 원본을 지우면 되살릴 수 없어요

✋ 따라 하기

  1. 왼쪽 메뉴에서 워크스페이스로 이동
  2. 어제 만든 디자인이 있는지 확인
  3. 작업할 디자인은 사본을 만들어 두기
💡 기억해요 원본은 건드리지 말고 사본에서 연습해요
▲ 목차로
STEP 02꼭 해요

배경 제거 · 리무브비지

📖 무엇인가요

사진에서 사람·물건만 남기고 배경을 지우는 기능이에요. 미리캔버스는 하루 5번만 되니 외부 사이트 리무브비지를 함께 써요.

🙋 이럴 때 써요

  • 강사 사진을 장표 배경 위에 자연스럽게 올릴 때
  • 제품·물건 사진을 깔끔하게 쓸 때

🗺️ 한눈에 보기

1🖼️원본 사진
➜
2✂️remove.bg 배경 지우기
➜
3⬇️내려받기
➜
4⬆️미리캔버스 업로드
⚠️ 주의해요 무료로 내려받으면 화질이 낮은 샘플이에요

👀 살펴보기

  • 미리캔버스 배경 지우기는 하루 5번만 쓸 수 있어요
  • 그래서 외부 사이트 리무브비지(remove.bg)를 써요
  • 무료로 받으면 화질이 낮은 샘플 파일이에요

✋ 따라 하기

  1. remove.bg 접속 → 사진 올리기
  2. 배경이 지워진 사진 내려받기
  3. 미리캔버스 「업로드」에 올려 장표에 넣기
💡 기억해요 어도비·윈도우 사진 앱도 되지만 리무브비지가 가장 깔끔해요
▲ 목차로
STEP 03같이 해요

딱 맞는 페이지

📖 무엇인가요

지금 장표 디자인에 맞춰 필요한 형식의 페이지를 알아서 만들어 끼워 주는 기능이에요. 조직도·벤다이어그램·CEO 소개 등을 고를 수 있어요.

🙋 이럴 때 써요

  • 교안 중간에 조직도·비교 장표가 필요할 때
  • 기관장·강사 소개 장표가 필요할 때

🗺️ 한눈에 보기

1📌장표 선택
➜
2🧩형식 고르기
➜
3✨같은 디자인으로 생성
➜
4➕자동 끼워 넣기
⚠️ 주의해요 비슷하게 만들어 주지만 배경색은 한 번 더 확인해요

👀 살펴보기

  • 빈 페이지를 따로 만들지 않아도 알아서 끼워 넣어 줘요
  • 조직도·벤다이어그램 등 여러 형식을 지원해요
  • 선택한 장표 디자인과 최대한 비슷하게 만들어요

✋ 따라 하기

  1. 넣고 싶은 위치의 장표 선택
  2. 「딱 맞는 페이지」에서 형식 고르기
  3. 기관장 소개는 「CEO 소개」 형식 활용
💡 기억해요 디자인이 비슷하게 나오니 배경색만 한 번 더 확인해요
▲ 목차로
STEP 04꼭 해요

다른 템플릿 페이지 가져오기

📖 무엇인가요

지금 템플릿에 없는 장표를 다른 템플릿에서 한 페이지만 골라 가져오는 방법이에요. 디자인이 다르니 색을 맞춰야 해요.

🙋 이럴 때 써요

  • 강사 소개처럼 지금 템플릿에 없는 장표가 필요할 때
  • 마음에 드는 장표 하나만 빌려 쓰고 싶을 때

🗺️ 한눈에 보기

1🅰️내 템플릿
➜
2🔍다른 템플릿 검색
➜
3📄한 페이지만 넣기
➜
4🎨배경색 맞추기
⚠️ 주의해요 「전체 적용」을 누르면 기존 장표가 다 바뀌어요 — 한 페이지만!

👀 살펴보기

  • 지금 템플릿에 없는 장표(예: 강사 소개)는 다른 템플릿에서 가져와요
  • 템플릿 메뉴에서 찾아 필요한 페이지만 넣어요
  • 디자인이 달라서 배경색 등을 맞춰야 해요

✋ 따라 하기

  1. 새 페이지 만들기
  2. 템플릿에서 「강사 소개」 검색
  3. 필요한 페이지 하나만 클릭해서 넣기
💡 기억해요 전체 적용이 아니라 페이지 하나만 넣어야 기존 장표가 안 바뀌어요
▲ 목차로
STEP 05꼭 해요

배경색 HEX 맞추기

📖 무엇인가요

HEX 코드는 색마다 붙은 번호예요. 앞 장표의 색 번호를 복사해 붙이면 색이 똑같아져요.

🙋 이럴 때 써요

  • 다른 템플릿에서 가져온 장표 색을 맞출 때
  • 기관 대표색을 정확히 쓸 때

🗺️ 한눈에 보기

1🟫앞 장표 배경색
➜
2📋HEX 코드 복사 #F4F1EA
➜
3📄새 장표 배경색
➜
4✅붙여 넣기 → 같은 색
⚠️ 주의해요 # 뒤 6자리(숫자·영문)를 빠짐없이 복사해요

👀 살펴보기

  • 가져온 장표 배경색을 앞 장표와 똑같이 맞추는 방법이에요
  • 배경색 메뉴를 누르면 HEX 코드(색 번호)가 보여요

✋ 따라 하기

  1. 앞 장표 배경 클릭 → 배경색 → HEX 코드 복사
  2. 가져온 장표 배경 클릭 → 배경색
  3. 복사한 코드 붙여 넣기
💡 기억해요 코드는 #과 숫자·영문 6자리예요 (예: #F4F1EA)
▲ 목차로
STEP 06같이 해요

자르기 vs 프레임 · 유료 사진 빼기

📖 무엇인가요

자르기는 사진의 네모 영역만 줄이고, 프레임은 동그라미·하트 같은 모양 틀에 사진을 담아요. 템플릿 속 유료 사진도 프레임에서 빼낼 수 있어요.

🙋 이럴 때 써요

  • 사진을 원형·특이한 모양으로 보여 줄 때
  • 템플릿의 유료 사진을 내 사진으로 바꿀 때

🗺️ 한눈에 보기

✂️ 자르기

  • 네모 모양만
  • 사진 크기·영역 조정
VS

🖼️ 프레임

  • 원·하트 등 여러 모양
  • 사진 빼내기·바꾸기 쉬움
⚠️ 주의해요 유료 사진이 남아 있으면 내려받을 때 결제 안내가 떠요

👀 살펴보기

  • 크기 조정·자르기로도 사진을 잘라 낼 수 있어요
  • 여러 모양으로 바꾸려면 프레임을 써요
  • 강사 사진을 누르면 이름이 「프레임」으로 보여요

✋ 따라 하기

  1. 템플릿 내려받기 → 「유료 콘텐츠 있음」 확인
  2. 해당 프레임 클릭 → 사진 빼내기
  3. 빼낸 유료 사진 삭제
💡 기억해요 프레임은 남기고 안의 사진만 빼면 내 사진을 넣을 수 있어요
▲ 목차로
STEP 07꼭 해요

빈 페이지 프레임에 사진 넣기

📖 무엇인가요

빈 페이지에 프레임을 놓고 사진을 끌어 넣으면 틀에 맞게 자동으로 맞춰져요. 프레임 안에서는 확대만 되고 원래보다 줄일 수는 없어요.

🙋 이럴 때 써요

  • 강사 얼굴 사진을 동그랗게 넣을 때
  • 사진을 디자인 틀에 깔끔히 맞출 때

🗺️ 한눈에 보기

1⬜빈 페이지
➜
2⭕요소 → 프레임
➜
3🧑사진 끌어 넣기
➜
4🔍확대해서 얼굴 맞추기
⚠️ 주의해요 상반신 사진은 확대해서 얼굴에 맞춰요

👀 살펴보기

  • 「요소」 메뉴에 여러 모양의 프레임이 있어요
  • 프레임에 사진을 끌어 넣으면 알맞게 맞춰져요
  • 프레임 안에서 사진은 확대만 되고 원래보다 줄일 수는 없어요

✋ 따라 하기

  1. 빈 페이지 만들기 → 요소 → 프레임
  2. 원하는 모양 고르기
  3. 사진 끌어 넣기 → 확대해서 얼굴에 맞추기
💡 기억해요 상반신 사진을 확대하면 얼굴 사진처럼 쓸 수 있어요
▲ 목차로
STEP 08시간 되면

프레임에 넣을 수 있는 것

📖 무엇인가요

프레임에는 사진 성질을 가진 것만 들어가요. 사진·비트맵·GIF·영상은 되고, 색을 바꿀 수 있는 일러스트(SVG)는 안 돼요.

🙋 이럴 때 써요

  • 움직이는 GIF·영상을 모양 틀에 넣을 때
  • 일러스트가 왜 안 들어가는지 헷갈릴 때

🗺️ 한눈에 보기

⭕ 들어가요

  • 사진 · 비트맵
  • GIF · 영상
VS

❌ 안 들어가요

  • 일러스트(SVG)
  • 색 바꾸는 그림 요소
⚠️ 주의해요 SVG = 색을 바꿀 수 있는 그림 요소예요

👀 살펴보기

  • 사진·비트맵·GIF·영상은 넣을 수 있어요
  • 일러스트(SVG) 요소는 넣을 수 없어요
  • SVG는 색을 페이지에 맞게 바꿀 수 있는 요소예요

✋ 따라 하기

  1. 프레임에 GIF 하나 넣어 보기
  2. 일러스트를 넣어 보고 안 들어가는 것 확인
💡 기억해요 비트맵은 사진과 성질이 같아요
▲ 목차로
STEP 09시간 되면

기본 vs 외곽선 프레임

📖 무엇인가요

기본 프레임은 틀 모양대로 사진을 채우고, 외곽선 프레임은 테두리 선이 있는 틀이에요.

🙋 이럴 때 써요

  • 배경을 지운 사진을 넣을 때 → 외곽선
  • 꽉 찬 사진을 넣을 때 → 기본

🗺️ 한눈에 보기

⬛ 기본 프레임

  • 틀 모양대로 꽉 채움
  • 일반 사진에 어울림
VS

🔲 외곽선 프레임

  • 테두리 선이 있음
  • 배경 지운 사진에 어울림
⚠️ 주의해요 배경이 투명한 사진은 외곽선 프레임이 더 어울려요

👀 살펴보기

  • 프레임은 기본 프레임과 외곽선 프레임이 있어요
  • 배경이 투명한 사진은 외곽선 프레임이 더 어울려요

✋ 따라 하기

  1. 배경 지운 사진을 두 프레임에 각각 넣기
  2. 어느 쪽이 나은지 비교
💡 기억해요 리무브비지로 지운 사진과 함께 쓰면 좋아요
▲ 목차로
STEP 10시간 되면

분할 프레임

📖 무엇인가요

장표를 여러 칸으로 나눈 프레임이에요. 캔바의 그리드처럼 칸마다 사진을 넣어 한눈에 비교할 수 있어요.

🙋 이럴 때 써요

  • 활동 사진 여러 장을 한 장표에
  • 시연 전·후 비교 장표

🗺️ 한눈에 보기

🖼️
활동 1
🖼️
활동 2
🖼️
활동 3
🖼️
시연 전
🖼️
시연 후
🖼️
결과
⚠️ 주의해요 사진 비율이 다르면 칸 안에서 위치를 조절해요

👀 살펴보기

  • 캔바의 그리드와 같은 기능이에요
