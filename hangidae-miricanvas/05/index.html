STEP 0

학습 목표와 전체 흐름

오늘은 2026년에 새로 생긴 미리캔버스 기능을 써 보고, 그중 핵심인 내용 시각화로 글을 도식으로 바꿔 봅니다.

학습 목표 설명

  1. 바뀐 편집 환경(최신 환경·편집 도구 모음)을 알고, 내 화면이 어떤 방식인지 확인할 수 있다.
  2. 작업 시간을 줄여 주는 신기능(스마트블록 이동, 사진 둥근 모서리, 안내선 격자, 투명도 숫자키, 도형 안 글자)을 직접 써 본다.
  3. 표·차트·슬라이드 쇼 신기능으로 교안 한 장을 발표용으로 다듬는다.
  4. 내용 시각화로 글을 도식(프로세스·비교 표·차트)으로 바꾸고, 결과를 확인·수정할 수 있다.
  5. 스마트블록 · 내용 시각화 · 딱 맞는 페이지 찾기 · 파워포인트 디자이너의 차이를 설명할 수 있다.

편집 환경이 바뀌었어요

같은 미리캔버스인데 옆 사람 화면과 다르게 보인다면, 이 STEP에서 이유를 찾을 수 있어요.

두 에디터가 하나로 — 최신 환경

  • 예전에 만든 디자인도 최신 환경에서 열려요. 따로 옮기거나 저장할 필요 없어요.
  • 사용자마다 순서대로 적용(2026-08-04 ~ 09-22).
  • 앞으로 나오는 편집 도구·템플릿·협업 기능은 최신 환경에서만 제공돼요.
주의드물게 글자·이미지 위치나 크기가 이전과 다르게 보일 수 있어요. 처음 들어갈 때 뜨는 안내에서 이전 버전과 비교해 볼 수 있어요.

STEP 2 실습

편집이 빨라지는 기능

교안 한 장 만들 때 자꾸 손이 가던 작업들이 짧아졌어요. 기능을 익힌 뒤 마지막 카드에서 표지 한 장을 다듬어 봅니다.

스마트블록 안 요소 바로 옮기기

스마트블록(디자인이 미리 짜인 묶음 요소)

예전엔 이동 아이콘(✥)을 잡아야 했지만, 이제 일반 요소처럼 바로 끌면 돼요.

  1. 블록을 한 번 클릭해 선택
  2. 옮길 요소에 마우스를 올려 테두리 확인
  3. 테두리가 보이는 요소를 클릭해 드래그

  • 여러 요소를 한 번에 옮길 수는 없어요 → 하나씩

사진 둥근 모서리

둥근 프레임 없이 사진에서 바로 둥근 정도를 정해요.

  1. 사진 클릭
  2. 왼쪽 속성 패널 아래쪽 둥근 모서리
  3. 슬라이더를 움직이거나 % 값 입력(예: 30)
안 되는 경우
  • 프레임 안 사진, 페이지·표 칸 배경 사진
  • 네 모서리는 같은 값만
  • 프레임·배경에 넣거나 사진 초기화하면 0%로 돌아감

안내선 한 번에 만들기 — 격자

  1. 전체 메뉴(≡) → 안내선 설정 → 안내선 추가
  2. 유형 고르기: 기본 / 가로 행 / 세로 열 / 격자
  3. 행·열, 간격, 여백(px) 입력
  4. 색상 고르기(분홍·노랑·초록·파랑·하늘색)
  5. 점선 미리보기를 보고 안내선 추가

투명도 숫자키 · 도형 안 글자

투명도 숫자키 — 요소를 고르고 숫자키 1~0을 누르면 투명도가 바로 바뀌어요.

도형 안에 글자 바로 입력 새 에디터 전용
도형과 글상자를 따로 넣고 정렬할 필요 없이, 도형을 더블클릭해 바로 입력해요.

주의[요소] 메뉴의 '도형' 탭에 있는 도형만 돼요. 모바일은 안 돼요.

실습 2 — 교안 표지 한 장 다듬기

  1. 새 디자인(프레젠테이션 16:9) 빈 페이지
  2. ≡ → 안내선 설정 → 안내선 추가 → 격자 3×3, 간격 20px, 여백 20px
  3. [사진]에서 수업 주제에 맞는 사진 1장 → 둥근 모서리 30%
  4. [요소 › 도형]에서 사각형 → 더블클릭해 아래 과정명 입력
  5. 도형을 고르고 숫자키 8로 투명도 조절
PPT보다 쉽게 만드는 미리캔버스 맞춤형 교안
한 걸음 더템플릿의 스마트블록을 하나 넣고, Ctrl+클릭으로 안쪽 아이콘만 골라 Alt+드래그로 복제해 보세요.
STEP 3 실습

교안용 표·차트·발표

교안에 자주 들어가는 표와 차트, 그리고 발표할 때 쓰는 기능이 좋아졌어요.

표 — 둥근 모서리 · 셀에 이미지 새 에디터 전용

  • 둥근 모서리: 표 전체 또는 셀 하나만 → 가격표·시간표 강조
  • 셀에 요소·이미지 넣기: 셀로 끌어다 놓기, 또는 Ctrl+C / Ctrl+V
  • 작게 맞추면 이모지처럼 글자 앞뒤에 배치
  • 우클릭 → 셀 배경으로 만들기 / 다시 우클릭 → 셀 배경 꺼내기

콤보 차트 새 에디터 전용

막대와 선 그래프를 한 차트에 넣어, 규모와 추세를 동시에 보여 줘요. 보고서·발표 자료에 좋아요.

슬라이드 쇼 클릭 애니메이션 새 에디터 전용

발표할 때 클릭할 때마다 요소가 하나씩 나타나요.

  1. 요소마다 애니메이션 효과 설정(각각 해야 해요)
  2. 에디터 위쪽 슬라이드 쇼
  3. 슬라이드 쇼 아래 설정(톱니바퀴) → 요소 등장 방식 '클릭'
  4. 슬라이드 쇼 재생
등장 순서레이어(겹친 순서)의 아래쪽 요소부터 차례로 나와요. 순서를 바꾸려면 레이어 순서를 바꾸세요. 일부 애니메이션 옵션은 적용되지 않아요.

PPTX 파일 가져오기 Pro

PDF에 이어 PPTX도 올려서 미리캔버스에서 이어서 편집해요.

  • 위치: 전체 메뉴(≡) → PDF · PPTX 가져오기(왕관 표시)
  • 조건: 최대 50MB · 300장 · 추출 요소 20,000개
무료 계정이라면시연만 보거나, 내 자료는 제미나이·노트북LM으로 정리해 텍스트로 가져오세요.

이미지로 템플릿 검색

갖고 있는 이미지와 비슷한 느낌의 템플릿을 AI가 추천해요.

  1. 미리캔버스 템플릿 페이지로 이동
  2. 검색창 오른쪽 끝 이미지로 검색 버튼
  3. 찾고 싶은 느낌의 이미지 올리기 → 비슷한 템플릿 표시
더 정확하게
  • 검색어로 먼저 검색한 뒤 이미지 올리기(예: "포스터" → 이미지)
  • 검색 결과에서 프레젠테이션·카드뉴스 등 종류를 고른 뒤 올리면 그 종류 안에서만
주의10MB 이하 이미지만 / 검색어는 입력 후 엔터까지 눌러야 반영 / 공지 기준으로 템플릿 페이지에서만 돼요.

참고 · 에디터 안 '비슷한 템플릿'

템플릿으로 시작한 디자인에서는 에디터 왼쪽에 비슷한 템플릿 창이 뜨는 화면도 확인됐어요.

이미지 분해 새 에디터 전용 Beta Pro

사진·일러스트를 구성 요소별로 나눠 필요한 부분만 고치거나 옮겨요. 배경 제거, 포인트 강조에 쓸 수 있어요.

  • 요소가 겹치지 않은 단순한 이미지일수록 잘 돼요.
  • 새 디자인 만들기 창 왼쪽에도 '이미지 분해(글과 요소를 고칠 수 있어요)' 항목이 있어요. 무료 계정에서는 왕관(유료) 표시가 붙어 있어요.

딱 맞는 페이지 찾기 Beta

  • 위치: 아래 페이지 목록 맨 왼쪽 돋보기+반짝이 아이콘
