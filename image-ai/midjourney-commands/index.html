기본 이미지 첨부 방법

  1. 디스코드 웹버전에서 이미지 첨부:채팅창의 + 버튼 클릭'파일 업로드' 선택로컬 파일에서 이미지 선택
  2. 드래그 앤 드롭:브라우저 창으로 직접 드래그채팅창 영역에 드롭
  3. 복사/붙여넣기:이미지 복사(Ctrl+C 또는 우클릭 복사)채팅창에 붙여넣기(Ctrl+V)

이미지 URL 관리

1. 디스코드에서 이미지 URL 얻기

  • 생성된 이미지 우클릭 → '링크 복사'
  • 이미지 URL 형식: https://cdn.discordapp.com/attachments/...

URL 사용 예시

1. 원본 URL 형식

https://cdn.discordapp.com/attachments/1186324921961369622/1186324999657439332/AnthropicLlama_Create_a_photorealistic_image_of_a_modern_skyscr_96fd6e16-6b84-4af9-8a23-a4f210c0a89f.png

2. 축약된 URL 형식

<1186324921961369622-1186324999657439332>

3. 실제 사용 예시

/imagine prompt: modern architecture, inspired by: <1186324921961369622-1186324999657439332>

/blend <1186324921961369622-1186324999657439332> <1186324921961369622-1186325012387639396>

/describe <1186324921961369622-1186324999657439332>

2. URL 축약 방법

  1. 디스코드 자체 축약:이미지 번호만 복사 (예: 1234567890)명령어에 번호만 입력 가능
  2. 외부 URL 단축 서비스 사용:bit.lyTinyURL

Rebrandly

  1. 참고: 일부 단축 URL은 작동하지 않을 수 있음

3. 이미지 URL 저장 및 관리

  1. 디스코드 채널 메시지 고정:중요 이미지 우클릭'메시지 고정' 선택고정된 메시지에서 빠르게 접근
  2. 디스코드 즐겨찾기 기능:메시지에 ⭐ 반응 추가'고정된 메시지' 탭에서 확인
  3. 개인 노트 작성:채널명/이미지번호 기록프로젝트별 URL 목록 작성

파일 제한사항

지원 형식:

• JPG/JPEG

• PNG

• GIF (정지 이미지만 사용)

  • • WEBP
  • 최대 파일 크기: 단일 파일 당 5MB
  • 해상도 제한: 없음 (자동 리사이징)

주의사항

  • 웹버전 특성상 클립보드 접근 권한 필요
  • 브라우저 설정에서 이미지 접근 허용 필요
  • 첨부 후 이미지 미리보기 확인 가능
  • 한 번에 최대 2개 이미지까지만 첨부 가능 (/blend 명령어 사용시)
  • URL은 디스코드 서버에 이미지가 존재하는 동안만 유효
  • 개인 채널에서 생성된 이미지는 해당 채널에서만 URL 접근 가능

각 명령어 상세 예시:

1. /imagine

프롬프트 예시:

/imagine prompt: hyperrealistic portrait of an elderly Asian fisherman, environmental portrait, weathered face, candid moment, natural lighting, Sony A7R4, 85mm f/1.4 lens --ar 4:5 --v 6 --q 2

​

결과물 설명:

- 깊은 주름과 풍파에 시달린 표정이 실감나게 표현

- 자연광의 부드러운 표현으로 인물의 감성 강조

- 85mm 렌즈 효과로 인한 자연스러운 배경 흐림

- 어부의 일상적 환경과 소품들이 자연스럽게 배치

2. /blend

프롬프트 예시:

/blend [도시 야경 사진] [안개 낀 숲 사진] --v 6

​

결과물 설명:

- 도시의 네온불빛과 자연의 신비로운 조화

- 건물 실루엣과 나무들의 자연스러운 혼합

- 안개 효과를 통한 몽환적 분위기

- 도시와 자연의 경계가 모호한 초현실적 장면

3. /describe

프롬프트 예시:

/describe [복잡한 도시 야경 사진]

​

결과물 설명:

- AI가 생성한 상세 설명문:

"A vibrant cityscape at night with towering skyscrapers illuminated by countless windows and neon signs. Heavy traffic creates light trails on the streets below, while the sky shows hints of deep blue twilight."

- 이 설명을 바탕으로 새로운 이미지 생성 가능

- 폭포수와 구름의 역동적인 표현

- 날개 표면의 섬세한 질감과 색상 그라데이션

1. 마음에 드는 이미지 선택

2. Make Variations 버튼 클릭

​

결과물 설명:

- 선택한 이미지와 유사한 새로운 버전들

- 미세한 차이의 다양한 변형

- 콘셉트는 유지하며 새로운 시도

- 더 많은 창의적 옵션 제공

4. Upscale 예시

작업 순서:

1. 이미지 선택 후 Upscale 버튼

2. 2x 또는 4x 배율 선택

​

결과물 설명:

- 원본 대비 2~4배 향상된 해상도

- 디테일의 선명한 보존

- 대형 출력에 적합한 품질

- 전문적인 용도로 활용 가능

5. Pan 예시

작업 순서:

1. 업스케일된 이미지에서 Pan 선택

2. 원하는 방향으로 확장

​

결과물 설명:

- 선택 방향으로 자연스러운 확장

- 기존 이미지 스타일 유지

- 새로운 요소의 자연스러운 추가

- 이음새 없는 확장 결과

6. Zoom Out 예시

작업 순서:

1. 이미지 선택 후 Zoom Out

2. 축소 범위 선택

​

결과물 설명:

- 더 넓은 장면 포함

- 기존 구도의 자연스러운 확장

- 새로운 컨텍스트 추가

- 원본의 분위기 유지

5. 프롬프트 작성 팁

5.1 기본 구조

/imagine prompt: [주제], [스타일], [분위기], [기술적 세부사항] --[파라미터]

5.2 권장 프롬프트 구성요소

  • 주제 (Subject)
  • 스타일 (Style)
  • 조명 (Lighting)
  • 구도 (Composition)
  • 컬러 팔레트 (Color Palette)
  • 카메라 앵글 (Camera Angle)
  • 렌즈 정보 (Lens Type)
  • 이미지 품질 표현 (Quality Descriptors)

완성된 프롬프트 예시:

프롬프트 예시:

/imagine prompt: professional portrait of a young entrepreneur [주제] in a modern corporate environment [배경], dramatic studio lighting [조명], shot on Phase One [카메라], 80mm prime lens [렌즈], shallow depth of field [효과], muted color palette [색감], ultra-detailed [품질] --ar 2:3 --v 6 --q 2

​

결과물 설명:

- 전문적인 기업 인물 사진 스타일

- 깊이감 있는 스튜디오 조명 효과

- 배경의 자연스러운 흐림 효과

- 고급스러운 색감과 톤

- 상업용 포트레이트 수준의 완성도
