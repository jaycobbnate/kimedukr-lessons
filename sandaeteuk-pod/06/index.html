미리캔버스

이제 미리캔버스로 옮깁니다. 지금은 쪽을 하나만 만듭니다. 그림·글까지 앉혀 본문 틀을 완성한 뒤 STEP 8에서 복제해 7쪽으로 늘립니다.

①따라하기

  1. 미리캔버스 로그인 → 새 디자인 만들기 → 직접 입력
  2. 148 × 210, 단위 mm → 단위가 없으면 px로 1748 × 2480
  3. 업로드 → 내 파일 업로드 → Ctrl로 01 ~ 07 일곱 장 한 번에
  4. 1쪽 빈 곳 클릭 → 위쪽 색 버튼으로 배경색 아이보리 — 이 쪽이 본문 틀이 됩니다

②비교 연습 · 사진을 배경으로

  1. 그림 한 장을 쪽에 올리고 오른쪽 클릭 → 배경으로 만들기

프레임 · 1:1 그림 칸

미리캔버스

프레임은 그림을 담는 창문입니다. 1:1로 만든 그림이라 정사각 프레임에 꼭 맞고, 필요하면 안에서 조금 키우거나 옮겨 주인공을 가운데로 둡니다.

①프레임 넣기

  1. 요소 → 프레임 → 기본 프레임 정사각형
  2. 크기 124 × 124mm (px 1465) · 위쪽 여백 12mm (px 142) · 가운데 정렬
  3. 03_기 그림을 프레임 위로 끌어다 놓기 → 1:1이라 꼭 맞게 들어감
  4. 프레임을 두 번 클릭 → 그림을 키우거나 옮겨 주인공을 가운데로

②장면별로 창문에 꼭

01 앞표지두 주인공 전신
02 소개두 얼굴 · 목도리 · 배낭
03 기뛰는 토끼 · 첫걸음 거북이 · 올빼미
04 승잠든 토끼 (멀리 거북이)
05 전지나가는 거북이 · 잠든 토끼
06 결리본과 두 주인공
07 뒷표지나란히 걷는 뒷모습

③입체로 보는 프레임 · 키우면 가장자리가 잘립니다

밝은 창문 = 책에 찍히는 부분 · 흐린 곳 = 잘려 나가는 부분. 막대로 확대해 보세요.

④내 속도로

막힐 때그림이 프레임에 안 들어가고 위에 얹히면 프레임 한가운데로 다시 끌어 놓으세요. 잘못하면 Ctrl + Z.
한 걸음 더캐릭터 소개 쪽을 원형 프레임 두 개로 바꿔 보세요. 같은 그림을 두 프레임에 넣고, 하나는 토끼 얼굴, 하나는 거북이 얼굴만 보이게 맞춥니다.
