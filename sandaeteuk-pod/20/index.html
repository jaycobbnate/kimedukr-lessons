화풍 정하기 — 무드보드 · 프로필 · 스타일 참조

미드저니에 내 책 화풍을 먼저 알려 줘요. 화풍이 정해져야 인물도 그 화풍으로 나와요.

시연2-1 무드보드(화풍 그림 모음판) 만들기

예시 · 할아버지의 라디오

책 그림 8장으로 무드보드 「할아버지의 라디오」를 만들었어요

「프롬프트에 사용」을 누르니 이 코드가 나왔어요.

--p m7519681894506995511
해석무드보드 「할아버지의 라디오」 화풍으로 그려 줘
내 것 만들기

순서

  1. 왼쪽 메뉴 「무드보드」 → 「새 무드보드」
  2. 제목 칸을 눌러 내 책 이름으로 바꿔요
  3. 그림 넣기 — 세 가지 중 편한 것 - 「이미지 업로드하기」: 내 컴퓨터의 그림 - 「링크에서 가져오기」: 핀터레스트 등 웹 그림 주소 - 「내 창작물에서 가져오기」: 미드저니에서 만든 내 그림
  4. 「프롬프트에 사용」을 눌러 나온 --p m숫자를 메모해요
그림 수 느낌
5~10장 수업용으로 충분해요. 화풍이 비슷한 그림만 모아요
20~40장 화풍이 더 단단해져요
100장 넘게 오래 쓸 내 화풍 저장고
주의무드보드 아이디는 꼭 --p m숫자로 써요. 앞의 m이 빠지면 오류가 나요.

예시는 무드보드로 했어요

책 그림이 이미 있어서, 그 그림들을 모아 무드보드로 만드는 게 가장 빨랐어요. 앞으로 모든 문장 끝에 --p m7519681894506995511를 붙여요.

내 것 만들기
방법 언제 문장 끝에 붙이는 것
무드보드 마음에 드는 그림이 여러 장 있을 때 --p m숫자
프로필(개인화) 미드저니에서 그림 고르기를 해 둔 분 --p 코드
스타일 참조 딱 맞는 그림 한 장이나 코드가 있을 때 --sref 코드
  • 오른쪽 위 「개인화」가 켜져 있으면 기본 프로필이 같이 들어가요. 내 코드만 쓰려면 끄거나 원하는 것만 켜요
  • 무드보드와 --sref는 같이 써도 돼요
막히면그림을 올렸는데 「프롬프트에 사용」이 안 보이면 그림이 다 올라갈 때까지 잠깐 기다려요. 코드를 잃어버리면 왼쪽 「무드보드」 목록에서 내 보드를 열면 다시 보여요.
한 걸음 더무드보드와 스타일 참조(--sref)를 같이 붙이면, 무드보드 화풍에 그림 한 장의 색감을 더할 수 있어요. 둘 다 붙인 뒤 4장을 비교해 보세요.
사용량무드보드를 만들 때는 시간이 들지 않아요.

이 책은 모든 글 쪽이 "기본 쪽" 하나예요. 아래 템플릿을 섞으면 넘기는 맛이 더 생겨요.

내 것 만들기
템플릿 모양 쓰는 곳
기본 쪽 쪽 제목 + 글 3~4줄, 가운데 보통 장면
대사 쪽 대사 한 줄만 크게 ("치, 지, 직!") 느낌표 장면 옆
소품 쪽 글 아래 구석에 작은 소품 그림 물건이 주인공인 장면
숨 고르기 쪽 한 문장만, 여백 넓게 장면이 바뀌는 곳
바탕색 옛날은 따뜻한 종이색, 지금은 연한 회청색 전체

규칙

  • 같은 템플릿 3쪽 연속 금지
  • 느낌표 장면(클로즈업) 옆에는 대사 쪽
  • 템플릿 하나를 완성하면 「페이지 복제」로 늘리고 글만 바꿔요

책 장면에 템플릿을 붙여 본 예시예요.

장 그림 샷 글 쪽 템플릿
1 롱샷 기본 쪽 (회청색)
2 풀샷 기본 쪽 (종이색)
3 롱샷 숨 고르기 쪽
4 클로즈업 ❗ 소품 쪽 (라디오)

내 것 만들기
위 스토리보드 장면마다 오른쪽 글 쪽 템플릿을 하나씩 정해 줘.

템플릿: 기본 쪽 / 대사 쪽 / 소품 쪽 / 숨 고르기 쪽
바탕색: 옛날 장면은 따뜻한 종이색, 지금 장면은 연한 회청색

규칙:
- 같은 템플릿 3쪽 연속 금지
- 느낌표 장면(클로즈업·로우·하이) 옆에는 대사 쪽
- 대사 쪽은 글에 있는 대사 중 한 줄만 크게

표: 장 | 그림 샷 | 글 쪽 템플릿 | 바탕색 | 이 쪽에 들어갈 글
막히면대사가 없는 이야기라면 대사 쪽 대신 "마음 한 줄"(예: 할아버지는 아무 말도 하지 않았다)을 크게 써도 돼요.
한 걸음 더미리캔버스에서 템플릿 네 가지를 한 쪽씩 먼저 만들어 두고, 페이지 복제로 늘리면 배치가 훨씬 빨라요.

그림과 글을 미리캔버스에 넣어 책으로 엮고, PDF로 내려받아 용량을 줄여요.

같이 실습8-1 미리캔버스 쪽 배치

예시 · 할아버지의 라디오

「할아버지의 라디오」 펼침면 — 왼쪽 그림, 오른쪽 글

내 것 만들기

쪽 배치 공식: 장면 N개면 2N + 6쪽 (10장면이면 26쪽)

예시 책은 27쪽이에요. 맨 끝에 빈 쪽 하나가 더 붙어 있어서 그래요. 공식은 내 책의 기본 쪽수를 잡는 기준이에요.

쪽 무엇
1 앞표지
2 · 3 앞속표지 · 목차
4 ~ 2N+3 장면 — 짝수 쪽 그림(왼쪽), 홀수 쪽 글(오른쪽)
2N+4 · 2N+5 판권 · 맺는 글
2N+6 뒷표지
  • 그림은 쪽에 꽉 차게 넣어요 (가는 길 B는 여기서 워터마크까지 잘라내요)
  • 글 쪽은 STEP 7 템플릿대로
  • 판권(책 정보 쪽: 발행일·저자·출판사·ISBN)은 부크크에서 받은 내용을 넣어요
막히면그림과 글의 좌우가 뒤바뀌면, 앞부분 쪽수가 홀수가 된 거예요. 앞속표지·목차 쪽이 빠졌는지 확인해요.

같이 실습8-2 PDF 내려받고 용량 줄이기

예시 · 할아버지의 라디오

「할아버지의 라디오」 PDF — 27쪽

27쪽 그림책 PDF가 약 7MB예요. 그림 원본을 그대로 넣으면 수십 MB가 되기 쉬워서, 20MB를 넘으면 줄여요.

내 것 만들기
  1. 미리캔버스 오른쪽 위 「다운로드」 → PDF 로 내려받아요
  2. 파일 크기를 확인해요 (파일 오른쪽 클릭 → 속성)
  3. 부크크 전자책은 20MB 이하여야 해요. 넘으면 줄여요 - 무료 PDF 압축 사이트에 올려 줄여요. 검색창에 「PDF 압축」을 치면 여러 곳이 나와요 - 압축 단계는 중간(권장)부터 해 보고, 그림이 뭉개지면 한 단계 약하게 해요
  4. 줄인 PDF를 넘겨 보며 그림·글이 깨진 쪽이 없는지 확인해요
주의인쇄용(종이책) PDF는 줄이지 않아요. 줄이는 건 전자책용만이에요.
막히면압축 사이트에서 파일이 안 올라가면 다른 압축 사이트를 써 보거나, 미리캔버스에 넣는 그림을 JPG로 바꿔 넣고 다시 내려받아요.
한 걸음 더줄인 PDF로 플립북(넘겨 보는 웹 책)을 만들어 패들렛에 링크로 올려 보세요.
