핵심8주 전체에서 오늘의 자리

지난주에는 이미지 한 장을 어느 자리에 꽂는지 배웠습니다. 오늘은 그 위에 같은 얼굴 · 같은 목소리를 얹습니다.

핵심오늘 만드는 것

[출력 순서] 1) 캐릭터 설정표: 이름 / 한 줄 성격 / 겉모습 특징 3가지(색·소품·실루엣) / 말투 / 어울리는 목소리 느낌 2) 캐릭터 고정 문장: 겉모습을 담은 영어 한 문장 3) 앵커 프롬프트(영어): 정면, 전신, 연회색 단색 배경, 중립 표정, 고른 빛, 글자 없음 4) 컷 목록 표: 컷 / 시작 이미지 / 끝 이미지 / 영상 프롬프트(영어) / 대사(한국어 15자 이내) / 자막(8자 이내) / 소리 [규칙] 한 컷 10초, 컷마다 카메라 움직임 하나, 대사는 컷당 한 줄, 실존 인물·상표·실제 기관 표장 금지, 영상 프롬프트 끝에 no music 또는 음악 지정. 핵심좋은 앵커의 다섯 조건 + 알아볼 특징 셋
