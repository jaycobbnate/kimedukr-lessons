STEP 1 · 에피소드 1 · 다 같이

컷 조립

강사가 한 번 하면 바로 따라 합니다. 목표는 군더더기 없는 30초 안팎.

원리그냥 붙여도 이어지는 이유

①~④는 앞 클립의 끝 그림 = 다음 클립의 첫 그림입니다(7차시 첫·끝 프레임). 그래서 붙이기만 해도 이어집니다. ④→⑤, ⑤→⑥은 장면이 바뀌는 곳이라 STEP 4에서 따로 다룹니다.

다 같이순서대로 깔기

  1. EP1_01~EP1_06을 한꺼번에 선택해 타임라인으로 끌어 놓기
  2. Space로 처음부터 끝까지 재생
  3. 지금 길이 확인: 약 36초 → 오늘 30초 안팎으로 줄입니다
막힐 때순서가 섞여 깔리면 하나씩 끌어서 자리를 바꿉니다. 타임라인이 작으면 Ctrl + 마우스 휠로 확대.

다 같이자르기·다듬기

  • 분할: 플레이헤드(재생 헤드)를 놓고 Ctrl+B (가위 아이콘)
  • 다듬기: 클립 양 끝을 안쪽으로 끌기
  • 되돌리기: Ctrl+Z
플레이헤드 = 타임라인 위 세로 시간 막대지금 화면에 보이는 위치를 가리키는 막대입니다. 분할(Ctrl+B)·정지(Freeze)·키프레임은 모두 이 막대가 있는 자리에서 적용됩니다. 캡컷에서는 플레이헤드(재생 헤드), 프리미어 프로에서는 현재 시간 표시기(Current Time Indicator, CTI)라고 부르는 같은 막대예요.
클립어디를
①걷는 앞부분이 길면 0.5~1초 줄이기
⑤앞의 조용한 부분은 1초 정도 줄이고, "메에에~" 끝나면 바로 끊기
⑥"…네, 잘 들었습니다" 뒤 1초 남기고 끊기

다 같이속도

클립 선택 → 오른쪽 속도 → 기본 1.0x.

  • ④ 까치발: 0.8x → 긴장감이 생깁니다
  • ③ 기다리는 장면이 늘어지면 1.2x (단, "네에~" 목소리가 변하는지 들어 보기)
대사가 있는 클립은 조심속도를 바꾸면 목소리 높낮이도 바뀔 수 있습니다. 대사를 살릴 클립은 1.0x 그대로 두거나, 속도 메뉴의 음높이(Pitch) 옵션을 확인하고 들어 봅니다.

다 같이원음 분리

  1. 클립 우클릭 → 오디오 추출 (여러 개를 한꺼번에 선택해서 안 되면 하나씩)
  2. 소리가 아래 오디오 줄로 떨어집니다
  3. 이제 클립별로 원음을 자르고, 줄이고, 끌 수 있습니다
원음 안에는 세 가지가 섞여 있어요대사 + 효과음 + 그록 배경음악이 한 덩어리입니다. 음악만 빼는 기능(보컬 분리)은 Pro이거나 AI 크레딧이 들 수 있어서 오늘은 볼륨으로 조절합니다.
한 걸음 더③의 "네에~ 네에~" 사이 빈 구간을 잘라 대답 간격을 좁혀 보세요. 웃음은 박자에서 나옵니다. 0.2초 차이로 두 번 내보내 비교해 보면 차이가 들립니다.
STEP 2 · 에피소드 1 · 다 같이

더빙 · 구글 AI 스튜디오

라디오 DJ처럼 사연을 읽는 목소리 하나로 여섯 클립을 한 작품으로 묶습니다.

원리왜 더빙을 하나

  • 그록 원음 대사는 클립마다 목소리가 조금씩 다릅니다.
  • 한국어 발음이 어색한 클립이 있습니다.
  • 컬투쇼는 원래 사연을 읽어 주는 방송이라 나레이션이 본래 맛에 가깝습니다.
원음은 버리지 않아요더빙을 입힌 뒤 클립마다 원음과 더빙 중 더 나은 쪽을 고릅니다(이 STEP 마지막 카드).

다 같이AI 스튜디오에서 만들기

  1. aistudio.google.com → 구글 계정 로그인
  2. 음성 생성(Generate speech) 화면 또는 Playground에서 이름에 TTS가 붙은 모델 선택
  3. 목소리 하나 고르기 (에피소드 1·2 같은 목소리로)
  4. 아래 대본을 붙여 넣고 실행 → 듣고 → 내려받기(WAV)
  5. EP1_더빙.wav로 8차시_캡컷 폴더에 저장
막힐 때
  • 메뉴 이름은 자주 바뀝니다. "TTS 모델", "목소리 선택", "내려받기" 세 가지만 찾으면 됩니다.
  • TTS 모델이 안 보이면 모델 목록 검색창에 tts.
  • 내려받기는 재생 막대 옆 점 세 개(⋮) 메뉴에 숨어 있기도 합니다.

복사에피소드 1 더빙 대본

첫 문단은 "읽는 방법" 지시예요화면에 스타일 지시(Style instructions) 칸이 있으면 첫 문단은 거기에, 나머지는 대본 칸에 넣습니다. 칸이 없으면 통째로 붙여 넣고, 지시문까지 소리 내어 읽혔으면 캡컷에서 그 부분만 잘라 냅니다.

다 같이캡컷에서 문장별로 맞추기

  1. EP1_더빙.wav 가져오기 → 오디오 줄에 놓기
  2. 문장 사이 빈 곳에서 Ctrl+B → 문장 조각으로 나누기
  3. 조각을 해당 클립 아래로 끌어 맞추기
  4. 더빙이 클립보다 길면: 클립을 선택하고 끝 장면에서 타임라인 위 도구 막대의 정지(Freeze) → 생긴 정지 화면 길이를 더빙에 맞추기. 또는 더빙을 1.1x로

음악·효과음 · 픽사베이

클립마다 끊기는 그록 음악 대신, 처음부터 끝까지 이어지는 한 곡을 깝니다.

원리소리는 층으로 쌓아요

그록은 클립마다 배경음악을 새로 만들어서, 클립이 바뀔 때마다 음악이 툭 끊기고 다른 곡이 나옵니다. 게다가 그록 클립은 앞 2초쯤 소리가 비어 있는 경우가 많아서 그대로 붙이면 중간중간 정적이 생깁니다. 원음은 줄이고, 픽사베이 음악 한 곡을 바닥에 깔고, 더빙이 나올 때는 음악을 낮추고, 반전 직전에는 비웁니다.

다 같이픽사베이 음악 받기

  1. pixabay.com/music 접속
  2. 아래 검색어 하나 복사 → 검색
  3. 미리 듣고 → 다운로드 (무료. 로그인을 요구하면 구글 계정으로 가입)
  4. 캡컷에 가져와 맨 아래 줄 0초부터 끝까지 깔기 → 길면 끝 자르기
막힐 때다운로드가 막히면 캡컷 왼쪽 오디오 → 음악에서 Pro 표시 없는 곡을 씁니다.

다 같이④→⑤ 전환 바꿔 끼우기

  1. 왼쪽 전환 탭
  2. 세 가지를 차례로 ④와 ⑤ 사이에 끌어 놓고 재생

  3. 하나 골라 길이 0.3~0.5초로 짧게
