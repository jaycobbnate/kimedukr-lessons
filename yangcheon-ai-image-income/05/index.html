5차시 · 레퍼런스 묶음 분석과 규격 보정

레퍼런스는 한 번에 묶어서,
규격은 정확하게 맞춥니다.

여러 사이트의 레퍼런스를 한 번에 모아 분석시키고, 수능 응원 사진 2장을 만들어 16:9 보정까지 마쳐 제출해요. 끝에는 다음 시간(PNG 요소)을 위한 배경 제거를 미리 맛봐요.

읽기5차시 녹화 영상

[현장강의] 수능 응원 레퍼런스 수집부터 사진 요소·포토피아 120DPI 규격까지유튜브에서 보기 ↗

영상이 재생되지 않으면 "유튜브에서 보기"를 눌러 주세요. 복습할 때는 교안의 STEP 순서대로 영상을 따라가면 돼요.

확인준비물

STEP 1

GPT 무료 플랜 한도 알기

모두 같은 조건으로 하려고 무료 플랜을 써요. 한도를 알고 요령껏.

읽기수업 당일 확인한 한도

항목한도
파일 첨부 횟수하루 약 3회 (시간이 지나면 풀림)
한 번에 첨부최대 10개 (한 번으로 셈)
프로젝트 소스5개

정책이 자주 바뀌어요. 정확한 숫자는 그날 GPT에게 물어보거나 화면 안내로 확인하세요.

다 같이zip으로 묶으면 한 번에

  1. 레퍼런스 이미지 여러 장을 폴더에 모으기
  2. 모두 선택 → 마우스 오른쪽 → 압축(ZIP)
  3. zip 파일 하나를 GPT에 첨부
첨부한 zip 파일 안의 이미지들을 모두 열어서 분석하고, 사람·사물·동물·배경으로 분류해 줘. 각 분류에 몇 장인지도 알려 줘.

수업에서 사진 20장 zip을 넣었더니 제대로 분류했어요. zip도 분석 잘해요.

한 걸음 더폴더째 읽히기

유료 기능(GPT 데스크톱의 워크 기능, 클로드 코워크 등)을 쓰면 컴퓨터 폴더를 연결해서 수천 장도 읽힐 수 있어요. 레퍼런스가 아주 많아지면 그때 고려하세요.

STEP 2

레퍼런스 사이트 넓히기

주제: 수능을 앞둔 학생 응원. 사진으로 검색해요.

다 같이어디서, 어떻게 찾나

사이트검색 팁
미리캔버스본진. 사진에서 "공부 응원". 이제 PPT 업로드 기능도 생겼어요
크라우드픽"학생 공부 파이팅", "공부 응원" — 사진 필터
핀터레스트"시험 응원", "학생 응원", "고등학생 공부". 공용 PC에선 로그인 요구가 뜰 수 있어요
게티이미지해외 스톡 사진의 구도 참고
클립아트코리아한국스러운 사진. 콘텐츠 타입을 포토로

다 같이내 요소 찾아보기

  1. 디자인허브 화면 위의 내 아이디 확인 (이메일과 달라요)
  2. 미리캔버스 검색창에 @아이디
  3. 내가 올린 요소가 판매 화면에 어떻게 보이는지 확인

읽기이번엔 배경 있는 사진으로

처음부터 배경 없는 이미지를 만드는 건 어려우니, 오늘은 배경이 있는 응원 사진으로 가요. 배경 없는 것은 끝 STEP에서 맛보고 다음 시간에 본격적으로.

STEP 3

GoFullPage — 검색 결과 한 장으로

하나씩 캡처하기 귀찮죠. 검색 결과 페이지 전체를 한 장으로 저장해요.

다 같이설치

  1. 크롬 오른쪽 위 ⋮
  2. 확장 프로그램 → Chrome 웹 스토어 방문하기
  3. "GoFullPage" 검색 (Full Page Screen Capture)
  4. Chrome에 추가 → 확장 프로그램 추가
  5. 계정 연동은 원치 않으면 안 해도 돼요
  6. 오른쪽 위 퍼즐 조각 아이콘 → GoFullPage 핀(고정)

다 같이캡처하기

  1. 핀터레스트·클립아트코리아 등에서 검색 결과 띄우기
  2. GoFullPage 아이콘 누르기 → 페이지가 자동으로 내려가며 찍혀요
  3. 새 탭에 결과 → 위쪽에서 PDF 저장 또는 이미지 저장, 편집(Edit)도 가능
  4. 마우스 오른쪽 → 복사해서 GPT에 바로 붙여도 돼요

작아 보여도 내려받아 보면 AI가 읽기에 충분한 크기예요.

다 같이레퍼런스로 분석 + 기획

GoFullPage로 저장한 이미지들(또는 zip)을 GPT 프로젝트에 첨부하고:

첨부된 이미지를 먼저 분석해 줘. 그다음, 미리캔버스 디자인허브 "사진" 요소에 적합한 수능 응원 이미지를 만들고 싶어. 등장인물은 학생 중심으로 최대 4명 이하. 1명 / 3명 / 4명 버전으로 미드저니 프롬프트 3가지를 추천해 줘. 글자는 넣지 않아.

흐름만 이해하면 문장은 내 말로 바꿔 써도 돼요.

STEP 4

기획 결과 읽기

핵심 방향: 수능을 앞둔 실제 고등학생들의 응원의 순간을 찍기. 글자는 피하기.

읽기샷의 종류

인원샷담는 범위
1명클로즈업얼굴 중심 — 표정이 주인공
3명미디엄 샷상체까지 — 손동작(파이팅)이 보임
4명와이드 / 미디엄 와이드장소까지 — 교실·교문 분위기

다 같이예시 프롬프트 (수업 흐름 기준)

1명

a Korean high school student smiling with a determined look, making a fighting pose with a fist, in a bright classroom, close-up, soft natural window light, realistic photo, no text --ar 3:4 --v 8.2

3명

three Korean high school students cheering each other before the college entrance exam, high-fiving in a classroom, medium shot, eye level, bright natural light, realistic photo, no text --ar 4:3 --v 8.2

4명

four Korean high school students in school uniforms cheering together in front of the school gate on an autumn morning, medium wide shot, slightly low angle, warm natural light, realistic photo, no text --ar 16:9 --v 8.2

GPT가 준 프롬프트를 그대로 써도 돼요. 위 예시는 막혔을 때 쓰세요.

STEP 5

만들고, 고르고, 내려받기

Raw와 Stylize를 바꿔 가며 비교한 뒤 2장을 골라요: 혼자 파이팅 1장 + 3~4명 1장.

읽기미드저니가 한국어가 됐어요

미드저니에 한국어 화면이 생겼어요. 번역이 덜 된 곳도 있고 어색해요. 영어가 편하면 ⋯ → 언어에서 English로 바꿔요.

다 같이Raw · Stylize 비교

  1. 프롬프트 그대로 1번
  2. 프롬프트 아래 프롬프트 사용 → Raw 끄고 Stylize 150으로 1번
  3. 비교: Stylize를 올리면 화장·헤어가 과해지고 "선남선녀"가 돼요

Stylize 기본은 100. 끝까지 올리면 현실에 없는 사람이 나와요.

읽기편집기 (Editor)

고치고 싶은 부분을 칠하면 그 부분만 다시 그려요(인페인팅). 배경을 투명하게 하는 기능은 없어요.

마음에 드는 사진이 조금 아쉬우면 편집으로 고치기보다 다시 생성하는 게 나을 때가 많아요.

다 같이고른 것만 한 번에 내려받기

  1. 마음에 드는 이미지에 좋아요
  2. Organize(정리) → 좋아요 필터
  3. 마우스로 드래그해서 여러 장 선택
  4. 아래 다운로드 → zip으로 받아져요

손 확인

고르기 전에 손가락을 꼭 보세요. 손이 이상하면 상품성이 없어요.

STEP 6

키워드 25개 — 이미지마다 따로

고른 이미지 zip을 GPT 프로젝트에 넣어요.

다 같이키워드 요청

내가 선택한 이미지입니다. 사진 두 장 각각 따로, 디자인허브 업로드용 제목 1개와 검색 키워드 25개를 쉼표로 구분해서 추천해 주세요.

한꺼번에 섞어 주면 "각각 따로"를 다시 말해요.

읽기GPT 프로젝트 vs 제미나이 젬

GPT 프로젝트

대화가 프로젝트 안에 쭉 모여 있어요. 업무에 쓰기 편해요.

제미나이 젬

최근 대화가 몇 개만 보이고 다른 대화와 섞여요. 노트북에 넣으면 "결과물"이 아니라 "지식"으로 저장돼요.

파일 첨부 한도가 스트레스라면 제미나이를 써도 괜찮아요.

STEP 7

지난주 제출한 요소 확인

요즘은 패턴을 파악하고 올려서 거부가 별로 없어요.

다 같이디자인허브에서

  1. 로그인 → 오른쪽에 거부됨 있는지
  2. 요소 → 상태 승인 / 전체 보기
  3. 요소를 클릭하면 저장한 메타데이터까지 보여요

다 같이미리캔버스에서

  1. 새 디자인 → 사진
  2. 검색창에 @내아이디
  3. 내 요소의 ⋯ → 제공자·키워드 확인
  4. 비슷한 사진 찾기 → 나와 결이 비슷한 작가들 보기

한 사람이 만든 요소는 결이 비슷해요. 그게 내 시리즈의 힘이에요.

STEP 8

업스케일 + 포토피아 보정

그냥 올리면 안 돼요. 해상도와 비율을 맞춰요.

다 같이① 업스케일

  1. 미드저니에서 고른 이미지 → Upscale (Subtle 또는 Creative)
  2. "HD로 일괄 생성"과 헷갈리지 마세요 — 그건 새 그림을 만들어요
  3. 완료되면 내려받기

다 같이② 포토피아에서 두 장 열기

  1. photopea.com → 파일 → 열기 (새 프로젝트 아님)
  2. 두 파일을 함께 선택 → 탭 두 개로 열려요

1:1, 3:4는 비율 걱정 없이 DPI만 바꾸면 돼요. 16:9가 애매해요.

다 같이③ 16:9 정확히 맞추기 (QHD 2560×1440)

AI가 만든 16:9는 미묘하게 정확한 16:9가 아니에요. 이미지 크기를 2560×1440으로 바로 넣으면 비율이 찌그러져요. 그래서 캔버스를 잘라 맞춰요.

  1. 이미지 → 캔버스 크기
  2. 상대값 체크 해제, 비율 사슬 해제
  3. 폭 2560, 높이 1440
  4. 기준점은 가운데 → 확인 (가장자리가 조금 잘려요. 사람 얼굴이 중요하지 주변은 괜찮아요)
  5. 이미지 → 이미지 크기 → 단위는 픽셀
  6. 리샘플 끄고 DPI 120으로 → 리샘플 다시 켜고 픽셀 값이 그대로인지 확인 → 확인
  7. 파일 → 내보내기 형식 → JPG, 품질 최대

리샘플 끄고 DPI 변경

픽셀은 그대로, DPI 숫자만 바뀌어요. 이미지가 뭉개지지 않아요.

리샘플 켜고 DPI 변경

픽셀이 같이 불어나요. 가로 2,500이 안 될 때만 이렇게 — 대신 약간 뭉개질 수 있어요.

다 같이④ 두 번째 이미지 (16:9 아님)

  1. 비율은 그대로
  2. 이미지 크기에서 리샘플 끄고 DPI 120
  3. 가로가 2,500보다 작으면 → 리샘플 켜고 DPI 120 (픽셀이 같이 늘어나요)
  4. JPG 최고 품질로 내보내기

다 같이⑤ 제출

  1. 디자인허브 콘텐츠 업로드 → 두 장 올리기 → 빨간 마크 확인
  2. 여러 개를 한꺼번에 올릴 때는 CSV 업로드 방법도 있어요
  3. 유형 사진 · AI 체크 꼭 · 유료/무료 선택
  4. 요소 이름 AI 채우기 → 키워드는 GPT 것을 붙여넣고 Enter → 필요 없는 것 지우기
  5. 메타데이터 저장 → 제출 → 심사 대기 확인
STEP 9

배경 제거 맛보기

다음 시간 PNG 요소 준비. 오늘은 일부러 배경 있는 사진으로 해 보며 "왜 처음부터 계획해야 하는지" 느껴 봐요.

다 같이① 편집기 스마트 선택

  1. 이미지 클릭 → 편집기 열기
  2. 스마트 선택 → 사람을 찍어 보기
  3. 잘 안 잡히면 레이어 초기화 → 지우기 브러시로 배경을 대충 지우기
  4. "배경을 순수 흰색으로" → 잘 안 바뀌어요

개체가 많은 사진이라 그래요. 단순한 이미지는 한 번에 잡혀요.

다 같이② Attach to Prompt로 흰 배경

  1. 이미지를 입력창 위 Attach to Prompt 칸으로 끌어오기
  2. 아래 문장 보내기
change the background to a plain white wall, nothing else in the background

배경이 깨끗한 흰색이면 배경 빼기가 쉬워요.

다 같이③ 어도비 배경 제거

  1. 흰 배경 이미지 PNG로 내려받기
  2. 새 창에서 "어도비 배경 제거" 검색 → 업로드
  3. 결과 내려받기
도구결과
어도비 배경 제거가장 깔끔, 원본 해상도 유지
remove.bg깔끔하지만 해상도가 확 줄어요

읽기③-1 책상까지 날아가면

사람 앞의 책상 같은 물건이 같이 지워질 때가 있어요. 포토피아에서 열어 자르기(크롭)로 아래를 잘라내면 자연스러워요. 대신 이미지가 작아지니 다시 키워야 해요.

읽기결론 — 처음부터 단색 배경으로

확인퀴즈

1. 여러 레퍼런스 이미지를 첨부 한도 걱정 없이 한 번에 넣는 방법은?

zip 하나는 첨부 한 번으로 세요.

2. 검색 결과 페이지 전체를 한 장으로 저장하는 크롬 확장은?

PDF·이미지로 저장할 수 있어요.

3. 16:9 이미지를 정확히 2560×1440으로 맞출 때 쓰는 메뉴는?

캔버스로 잘라야 비율이 찌그러지지 않아요.

켜 두면 픽셀이 같이 불어나요.

처음부터 단색·그러데이션 없는 배경이어야 깔끔하게 빠져요.
