4차시 · 승인 패턴 학습에서 첫 업로드까지

승인받은 이미지에서 배우고,
오늘 첫 요소를 올립니다.

AI에게 승인 사례의 패턴을 학습시켜 전략 가이드(md)로 만들고, 그 기준으로 만든 사진을 규격에 맞춰 디자인허브에 제출해요.

읽기4차시 녹화 영상

[현장강의] 디자인허브 수익화 올인원 — GPT 지식 프로젝트부터 심사 접수까지유튜브에서 보기 ↗

영상이 재생되지 않으면 "유튜브에서 보기"를 눌러 주세요. 복습할 때는 교안의 STEP 순서대로 영상을 따라가면 돼요.

확인준비물

STEP 1

지난 결과 돌아보기

왜 패턴 학습이 필요한지, 지난번 결과에서 먼저 느껴 봐요.

읽기안 팔리는 사진의 신호

  • 너무 시네마틱 — 영화 같지만 아무도 안 사요. 쓸 곳이 적어요
  • 손가락·팔다리 이상 — 정확히 보면 심사에서 떨어져요
  • 인원이 너무 많음 — 초점이 흩어져요
  • 뒤 사람이 이상한 행동 — 지나가야 할 사람이 따봉을 하는 등

읽기미드저니를 쓰는 이유

남과 차별되는 미학 한 스푼을 넣기 위해서예요. 하지만 그 한 스푼이 너무 많으면 판매용으로 쓸 곳이 줄어요.

피사체는 1~2명, 초점은 분명하게. 단체 사진은 어색해지기 쉬워요.
STEP 2

① 승인 레퍼런스 모으기

본진(미리캔버스)에 이미 올라가 있는 것 = 승인받은 것. 이걸 AI에게 보여 줄 거예요.

읽기어디서 모으나

사이트쓰임
미리캔버스최우선 — 승인 사례 그 자체
크라우드픽함께 보면 좋음
픽사베이·펙셀스해외 이미지라 한국 소재엔 애매
핀터레스트창작 아이디어용. 승인 패턴 학습엔 안 맞음

다 같이프레임에 모아 한 장으로

  1. 미리캔버스 → 프레젠테이션 (화면이 제일 커요)
  2. 요소 → 프레임 → 아래로 내려 분할 프레임 (여러 칸짜리)
  3. 왼쪽 사진에서 주제 검색 → 사진을 프레임 칸에 끌어다 놓기
  4. 다 채우면 Win+Shift+S로 캡처

사진 하나에서 ⋯ → 비슷한 사진 찾기를 누르면 같은 결의 사진만 모아 볼 수 있어요.

읽기주제는 쉬운 것으로

"학생 응원"처럼 검색이 잘 안 되는 주제는 레퍼런스가 부족해요. 할로윈, 가을 등산처럼 사진이 많은 주제로 연습하세요. 패턴이 보이는 게 먼저예요.

STEP 3

② AI에게 패턴 학습시키기

지난 시간 GPT는 규격에만 충실해서 이상한 이미지를 기획했어요. 이번엔 승인 사례를 보여 주고 배우게 해요.

다 같이패턴 분석 프롬프트

GPT 프로젝트 채팅에 캡처 이미지를 첨부하고:

지금 첨부한 이미지는 미리캔버스 디자인허브에서 승인받은 유·무료 사진 요소입니다. 사진의 구도, 뷰, 샷, 앵글, 조명, 색감, 인원수, 피사체 크기 등을 분석해서 심사에 최적화된 이미지의 패턴을 보고해 주세요. 알기 쉽게 개조식으로 설명하고, 마지막에 표로 정리해 주세요.

레퍼런스는 한 번에 끝내지 말고 계속 넣으세요. 한두 장으로 판단하면 성급한 일반화가 돼요.

읽기수업에서 나온 패턴 예시

항목승인 사례에서 강하게 보이는 패턴
피사체인물 중심, 대상이 분명하고 크게
인원많지 않게 (1명·3명·5명처럼 적게)
앵글·거리로우 앵글, 근거리
조명·색감밝고 자연스럽게, 과한 연출 없이
배열사람마다 배치가 다르게, 단조롭지 않게
STEP 4

③ 학습한 패턴으로 프롬프트 받기

이제 주제만 말하면 위 패턴에 맞춰 프롬프트를 써 줘요.

다 같이주제 요청

위에서 학습한 내용으로, 고등학생들이 교실에서 수능 잘 보자고 파이팅하는 장면의 미드저니 프롬프트를 작성해 줘. 비율, 조명, 뷰·샷·앵글을 모두 고려하고, Raw를 넣을지 말지도 판단해 줘. 버전은 8.2야.

수업 결과: 인원을 확 줄이고, Stylize를 50으로 낮춘 프롬프트가 나왔어요.

읽기Stylize 50이란?

Stylize(스타일라이즈)는 미드저니 미학의 양이에요. 기본 100. 50으로 낮추면 미드저니가 덜 꾸미고 힘을 뺀다는 뜻이에요. 판매용 사진에는 이게 더 자연스러울 때가 많아요.

STEP 5

성공한 대화를 매뉴얼로

잘된 대화 기록은 업무 매뉴얼이에요. AI가 가장 잘 읽는 md 파일로 만들어 프로젝트에 넣어요.

다 같이md로 정리

지금까지 너와 내가 조사한 내용을 기반으로 MD 문서로 만들어 줘. 제목은 "미리캔버스 사진 요소 제작 전략 가이드". 승인 패턴, 프롬프트 공식, 피해야 할 것, 체크리스트 순서로 정리해 줘.

"가이드"라는 이름이 애매하면 GPT에게 물어보세요. 수업에서는 공식 규격 가이드와 구별해 전략 가이드로 정했어요.

다 같이내려받아 열어 보기

  1. md 파일 내려받기
  2. 더블클릭으로는 안 열려요 → 마우스 오른쪽 → 연결 프로그램 → 메모장
  3. 그냥 글이에요. 앞에 기호만 조금 달라요

  1. GPT 프로젝트 홈 → 소스에 md 파일 추가
  2. 이제 프로젝트에 지식이 두 개: 공식 규격 가이드 + 내가 만든 전략 가이드
  3. 새 채팅에서 테스트
소스의 사진 전략 가이드를 기반으로 분석해서, 유치원 할로윈 파티 사진 요소의 미드저니 프롬프트를 제시하고 이유를 알려 줘. 미드저니 8.2 기준이야.

레퍼런스를 계속 넣어 분석을 돌린 뒤 md를 다시 만들어 교체하세요. 가이드가 두꺼워질수록 앞 단계(조사·기획)가 필요 없어져요.

STEP 6

⑤ 미드저니에서 고르고 다듬기

오늘 올릴 이미지 1~2장을 정해요.

다 같이다시 만들기 버튼

버튼하는 일
Rerun같은 프롬프트·설정으로 다시 4장
Run batch HD같은 조건을 HD로 다시 (고해상도)
Use (T)프롬프트+파라미터 전부 입력창으로 — 다시 쓰기 귀찮을 때

다 같이여분의 손발 검사

확대해서 손가락 수, 다리 개수, 얼굴 모양을 꼭 보세요. 6손가락보다 다리 하나 더 있는 게 더 자주 나와요.

하나라도 이상하면

그 이미지는 올리지 않아요. Rerun이나 Vary로 다시.

읽기해상도 — HD냐 업스케일이냐

HD로 만들었다면

내려받아 속성을 보면 가로 2,500픽셀 이상이에요. 그대로 써도 돼요.

Standard로 만들었다면

픽셀이 모자라요. 이미지 마우스 오른쪽 → Upscale.
Subtle 그대로 키우기 / Creative 디테일·명암 보강

업스케일은 시간이 걸리고 사용량도 써요. 오늘은 Creative로 해 봐요. AI가 만든 16:9는 미묘하게 비율이 틀어져 있기도 해요 — 다음 시간에 맞춰요.

STEP 7

④ 검색 키워드 만들기

디자인허브 키워드는 최대 25개. 검색에 걸리는 길이에요. AI는 업로드 화면에서 5개밖에 안 채워 줘요.

다 같이승인 요소의 키워드 학습

  1. 미리캔버스에서 승인된 요소 하나 열기 → 키워드가 보이는 화면
  2. Win + Shift + S → 위 메뉴의 텍스트 추출 버튼 (윈도우 11)
  3. 키워드 영역을 끌면 글자가 복사돼요
  4. GPT에 붙여넣고 아래 문장
이미지를 생성하고 디자인허브에 업로드하려면, 그 사진에 어울리고 해당하는 위와 같은 키워드를 넣어야 합니다. 학습하세요. 최대 키워드 수는 25개입니다.

다 같이내 이미지의 키워드 뽑기

  1. 미드저니에서 내 이미지 클릭 → Copy Image
  2. GPT 채팅에 붙여넣기
이 이미지의 디자인허브 업로드용 제목 1개와 검색 키워드 25개를 쉼표로 구분해서 뽑아 줘.

GPT에서 이미지 붙여넣기가 안 되면 제미나이(또는 강사가 공유한 디자인허브 도우미 젬)를 써도 돼요.

STEP 8

⑥ 포토피아로 규격 맞추기

포토샵과 비슷한 무료 웹 편집기예요. 설치 없이 브라우저에서.

다 같이따라 하기

  1. 새 창에서 photopea.com → 무료로 사용 (광고가 떠도 괜찮아요)
  2. 파일 → 열기 (컴퓨터에서 열기) → 업스케일한 이미지
  3. 이미지 → 이미지 크기
  4. 종횡비 유지 체크 (체인 아이콘이 연결된 상태)
  5. 가로가 2,500보다 작으면 2,500 이상으로
  6. DPI 72 → 120
  7. 확인
  8. 파일 → 내보내기 형식 → JPG, 품질을 최대로 → 저장

배경이 있는 사진

무조건 JPG

용량

품질 100으로 올려도 수업 이미지는 약 8MB. 기준 50MB 이하라 괜찮아요.

리샘플(Resample)이 뭐예요?

켜져 있으면 DPI를 바꿀 때 픽셀도 같이 불어나요. 이번처럼 픽셀을 늘려야 할 때는 켜 둔 채로 진행해요. 5차시에 리샘플을 끄고 DPI만 바꾸는 방법도 배워요.

STEP 9

⑦ 디자인허브 첫 업로드

작업이 다 됐으면 올리는 건 어렵지 않아요.

다 같이업로드 순서

  1. 디자인허브 → 단일 요소 업로드 → 파일 선택 → 방금 저장한 JPG
  2. 빨간 마크가 안 뜨면 정상. 뜨면 규격 문제 — 손을 들어 주세요
  3. 다음
  4. 유형: 사진 (배경 아님) / AI로 만듦 체크
  5. 판매: 프리미엄(유료) 또는 무료
  6. 요소 이름: AI 채우기 써도 돼요
  7. 키워드: AI가 5개만 채워요 → GPT가 만든 키워드를 쉼표 구분 그대로 붙여넣고 Enter → 쭉 들어가요. 25개 넘으면 안 맞는 것 지우기
  8. 메타데이터 저장 → 제출

메타데이터는 "데이터 안의 데이터"예요. 사진을 찍으면 날짜·장소가 남듯, 요소에도 이름·키워드 정보를 저장해요.

읽기유료냐 무료냐

시리즈로 만든다면 하나는 무료(미끼, 내 작품 홍보), 나머지는 유료로 하는 것도 좋은 전략이에요.

읽기심사 대기 vs 심사 중

상태삭제
심사 대기가능 — 아무 영향 없음
심사 중불가

반려가 쌓이면 좋지 않아요. 연습으로 올렸다가 아니다 싶으면 심사 대기일 때 빨리 지우세요.

읽기앞으로의 업로드 리듬

심사는 열흘 정도 걸려요. 제출 대기 20개가 다 차면 더 못 올려요. 집에서 20개를 몰아 올리지 말고 수업마다 2개 정도씩.
STEP 10

사진에서 배경을 빼면

사진은 디자인허브에서 잘 팔리는 요소는 아니에요. 같은 사진에서 배경을 빼면 또 하나의 요소가 돼요. 원소스 멀티유즈.

읽기배경 뺄 이미지는 처음부터 다르게

미드저니는 아직 배경을 투명하게 만들지 못하고 무조건 배경을 채워요. 그래서 처음부터 단색 배경으로 만들어야 나중에 빼기 쉬워요.

웹 기반 배경 제거는 100% 업로드 후 처리돼서 내려와요. 알고 쓰세요.

STEP 11

막힘 사전

1. AI가 가장 잘 읽는, 성공한 대화를 매뉴얼로 남기는 파일 형식은?

마크다운(md)은 메모장으로도 열리는 글 파일이에요.

2. 사진 요소 규격에 맞춘 DPI 숫자는?

미드저니 기본은 72라 포토피아에서 120으로 바꿔요.

3. 심사 중인 요소를 지울 수 있을까요?

심사 대기일 때만 지울 수 있어요.

4. Stylize를 100에서 50으로 낮추면?

미드저니 미학의 양을 줄여요.
