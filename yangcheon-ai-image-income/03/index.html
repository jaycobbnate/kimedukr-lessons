확인준비물

STEP 1

시작 전 점검

남은 시간, 버전, 프로필을 확인하고 시작해요.

다 같이남은 사용량

  1. ⋯ → Manage Subscription
  2. 내가 쓴 양과 남은 양 확인

Basic은 약 200장 분량이에요. 시간으로 적혀 있어도 모델·설정에 따라 줄어드는 속도가 달라요.

Relax 모드

Standard 플랜부터 있어요. 무제한이지만 다른 사람 작업이 먼저라, 요즘은 라면 하나 끓여 먹고 올 만큼 걸리기도 해요.

다 같이버전과 프로필

  • 8.2와 7을 함께 쓰는 이유: 사용량과 화풍 차이
  • 프로필은 열어야(활성화) 쓸 수 있어요. V7·V8 둘 다 열려 있는지 Personalize에서 확인
  • 무드보드는 따로 열지 않아도 바로 쓸 수 있어요
  • V6은 예전의 뭉개지는 맛을 좋아하는 분만

다시 한 번

설정에서 Video Batch Size 1 확인. 손가락 실수 한 번에 시간이 사라져요.

STEP 2

모델마다 성격이 달라요

같은 프롬프트를 모델만 바꿔서 보내 봐요.

다 같이같은 문장, 세 모델

Korean model posing
  1. 설정 아무것도 안 건드리고 기본 모델(8.2)로 → 실사 2장, 일러스트 2장처럼 섞여 나와요 (뭘 좋아할지 몰라 다양하게 준비)
  2. Version을 Niji 7로 → 같은 문장 보내기
  3. Niji 6으로 → 같은 문장 보내기 (조금 더 빨라요)

기본 모델

전문 화가를 고용한 느낌. "나는 예술가요"가 들어가 있어요.

니지 (Niji = 무지개)

일러스트·만화용. 프롬프트에 충실하고 실패가 적어요. 대신 일본 애니메이션 톤이 섞여요.

다 같이고양이 테스트

cat

Niji 6으로 보내면 고양이 대신 고양이 귀를 한 소녀가 나오기도 해요. Niji 7은 덜해요. 모델이 무엇을 많이 배웠는지가 결과에 드러나요.

읽기언제 무엇을

  • 일러스트·만화 요소 → 니지로 시작하면 프롬프트에 화풍을 길게 안 써도 돼요
  • 또는 프로필·무드보드로 — 가끔 엉뚱한 결과(삑사리)가 나와요
  • 니지도 프로필을 만들 수 있어요 (Unlock 표시)

한 걸음 더

PNG·SVG 요소는 보통 일러스트예요. 니지 프로필을 하나 만들어 두면 6차시 이후 요소 제작이 빨라져요.

STEP 3

참조(레퍼런스) 기능의 변화

입력창의 이미지 버튼 — 사진을 첨부해 따라 그리게 하는 기능이에요.

읽기버전 7과 8의 참조 메뉴

버전 7버전 8.x
이미지 프롬프트 — 글 대신 이미지로 내용 지시이미지 프롬프트
스타일 레퍼런스 — 화풍·질감스타일 레퍼런스
옴니 레퍼런스 — 사진 속 사람·사물을 따라함없어짐 → Attach to Prompt가 그 역할

읽기옴니 레퍼런스 (버전 7)

인물 사진을 넣고 "사무실 의자에 앉아 일하는 직원, 정면"이라고 쓰면 그 사람의 얼굴·머리 모양을 따라해요.

강도(--ow)를 400까지 올리면 화장·점·옷·배경의 초점 흐림까지 따라해요. 6버전은 얼굴만, 7버전부터는 사람·동물·물건 무엇이든 따라해요.

읽기초상권 경고

실존 인물은 연습에서만

유명인 사진을 넣으면 초상권 주의 안내가 떠요. 판매용 요소에는 실존 인물·연예인 얼굴을 절대 쓰지 마세요. 심사에서도 걸리고 법적 문제가 됩니다.

판매용으로는 내가 만든 캐릭터나 내가 만든 인물 이미지를 참조로 써요.

STEP 4

Attach to Prompt 실습

첨부한 대상을 유지하면서 새 장면에 자연스럽게 넣어 줘요. 시리즈물을 만들 수 있어요.

다 같이따라 하기

  1. Version 8.2 확인
  2. 입력창 이미지 버튼 → Upload → 내 캐릭터(또는 지난번 결과) 올리기
  3. 올린 이미지를 Attach to Prompt 칸으로
  4. 아래 프롬프트 보내기
the character is sitting on a subway seat, gazing out the window, the subway is running above ground and scenery is passing by outside, soft daylight

이미지를 첨부하면 Edit 메뉴도 생겨요.

읽기이미지 프롬프트와 무엇이 다른가

이미지 프롬프트

이미지를 분석해서 글처럼 써 넣는 방식. 강아지 캐릭터를 넣고 "사람이 뛰어간다"고 쓰면 충돌해서 개 사람이 나와요.

Attach to Prompt

그 대상을 포함한 채 새 장면을 자연스럽게 만들어요. 비율까지 레퍼런스를 유지해요. GPT·나노바나나와 비슷한 방식이에요.

한 걸음 더시리즈물로 늘리기

같은 캐릭터를 첨부한 채 장면만 바꿔 3장을 만들어 보세요. 판매 요소에서 "시리즈"는 같은 캐릭터·같은 화풍이 유지되는 묶음이에요.

the character is reading a book on a bench in an autumn park, warm afternoon light, full body
the character is holding a cup of coffee by a cafe window, rainy day outside, medium shot
the character is waving hello with a big smile, plain light gray background, full body

예전에는 미드저니에서 만든 캐릭터를 고치려면 GPT로 옮겨 가야 했어요. 이제는 미드저니 안에서도 충분히 가능해요.

STEP 5

Animate — 5초 움직임

잘 나온 이미지를 짧은 영상으로. 상품을 잠깐 보여 주는 쇼핑몰 영상에 딱 맞아요.

다 같이두 가지 방법

  1. 마우스 올리기 — 이미지 위에 Animate 버튼 → 바로 생성
  2. 클릭 후 아래 메뉴 — Animate Image 섹션에서 고르기
메뉴뜻
Auto알아서 움직임
Manual움직임 프롬프트를 직접 고쳐 쓰기
Low / High motion움직임 크기 (큰 차이는 아님)
Loop첫 장면으로 다시 돌아와 계속 반복

읽기쓸 곳과 한계

  • 루프는 움직임이 크면 어지러워요 → Loop + Low motion
  • 손·손가락 동작은 아직 어색해요
  • 상품 돌리기, 모델이 잠깐 들고 있는 5초 영상에 최고

시간 주의

영상은 시간을 가장 많이 써요. 꼭 필요한 이미지만, Video Batch Size 1로.

STEP 6

디자인허브 전용 제작 도우미

지난 시간 제미나이 노트북은 가이드 첫 페이지만 읽고 엉뚱한 답을 했어요. 오늘은 GPT 프로젝트로 다시 만듭니다.

읽기왜 바꾸나

  • 노트북에 가이드 주소만 넣으면 그 한 페이지만 분석해요
  • 그래서 "사진인데 배경 없는 이미지" 같은 잘못된 프롬프트가 나왔어요
  • GPT 프로젝트는 지침에 "하부 페이지까지 근거로" 같은 규칙을 넣을 수 있어요

무료 플랜으로 해요

모두 같은 조건에서 하려고 무료 플랜으로 진행해요. 생각(Thinking) 버튼을 켜면 더 똑똑해져요.

다 같이프로젝트 만들기

  1. 왼쪽 프로젝트 → +
  2. 이름: 미리캔버스 디자인허브 요소 제작 도우미
  3. 메모리: 프로젝트 전용 메모리 선택
  4. 프로젝트 만들기
  5. 상단 ⋯ → 프로젝트 설정 → 지침에 아래 글 붙여넣기 → 저장

메모리는 처음에만 정할 수 있어요

업무용 프로젝트는 내 일반 대화 취향이 섞이면 안 돼요. 만들 때 "프로젝트 전용"을 고르세요. 나중에 못 바꿔요.

다 같이프로젝트 지침

[프로젝트 목적] 이 프로젝트는 미리캔버스 디자인허브(기여자)에 올릴 요소를 기획·제작·등록하는 업무 전용이다. [근거 원칙] 1. 모든 답은 미리캔버스 디자인허브 공식 가이드(업로드 화면의 "가이드 자세히 보기"로 열리는 가이드 페이지와 그 하부 페이지 전체)를 최우선 근거로 한다. 2. 가이드에 없는 규정을 임의로 만들지 않는다. 확인되지 않으면 "가이드에서 확인 필요"라고 쓴다. 3. 규격·심사 기준을 말할 때는 근거가 된 가이드 페이지를 함께 밝힌다. [작업 범위] - 요소 유형(사진, 배경 제거 사진, 일러스트, PNG, SVG, GIF 등)별 규격과 주의사항 안내 - 판매 소재 기획 (시즌·용도·대상) - 미드저니 프롬프트 작성 (영문, 한국인이 필요하면 Korean 명시, 글자·로고·상표 넣지 않음) - 제목·검색 키워드(최대 25개, 쉼표로 구분) 작성 - 업로드 전 이미지 검토 [답변 방식] - 개조식으로 짧게, 필요하면 표로 - 프롬프트는 복사할 수 있게 따로 블록으로 - 사용자가 미드저니를 쓴다고 하면 미드저니 기준으로 답한다

강사가 톡방에 파일로도 드려요. 파일로 받으면 지침 대신 소스(지식)에 넣어도 돼요. 무료 플랜은 소스 파일 5개까지예요. 가이드 페이지 주소를 지침 끝에 붙여 넣어 두면 더 정확해요.

다 같이테스트 질문

미리캔버스 디자인허브 요소 중 "사진" 유형의 제작 가이드를 알려 줘. 근거 페이지도 같이.

답 아래에 가이드 페이지(슬래시페이지) 링크가 붙어 나오면 제대로 찾아본 거예요. 눌러서 원문과 대조해 보세요.

STEP 7

무엇을 만들까 — 레퍼런스부터

상상만으로 정하지 않아요. 파는 곳(본진)에서 무엇이 승인되고 쓰이는지 먼저 봐요.

다 같이주제 추천 받기

미드저니로 만들 거야. 11월 대한민국 행사·시즌 중에서 디자인허브 "사진" 요소로 만들기 좋은 주제를 추천해 줘. 추천 이유와 실제 수요(누가 어디에 쓰는지)도 함께.

수업에서는 김장, 수능, 빼빼로데이가 나왔어요. "시즌 묶음 10개" 같은 제안이 와도, 제출 대기가 20개까지라 적당히 넣어요.

다 같이미리캔버스에서 레퍼런스 보기

  1. 미리캔버스 로그인 (구글 계정이면 바로) → 새 디자인
  2. 왼쪽 사진에서 "김장", "수능", "빼빼로" 검색
  3. 마음에 드는 사진의 ⋯ → 비슷한 사진 찾기
  4. 어떤 구도·인원·소품이 승인됐는지 눈으로 익히기

읽기레퍼런스에서 읽어 낼 것

  • 상표가 보이면 승인이 거의 안 나요 — 과자 이름, 로고 금지
  • 트렌드: 빼빼로를 주고받는 사진은 잘 안 팔려요. 실제로는 상자로 주니까요. 반대로 "없는 틈새"를 노릴 수도 있어요
  • 수능은 학원에서 많이 써요 — "수능 대박, 파이팅" 응원 장면이면 충분
  • 머리띠 두른 수험생 같은 옛날식 표현은 요즘 학생들에게 안 통해요

다른 레퍼런스 사이트

크라우드픽 — 저작권 걱정 없는 이미지, 김장·수능 검색해 보기
핀터레스트 — 트렌드 보기. 상업용·비상업용이 섞여 있어 모티브만 가져와요. 너무 비슷하게 만들면 위험해요.

STEP 8

GPT와 주고받으며 다듬기

제일 쉬운 수능 응원부터. 한 번에 좋은 결과를 기대하지 않아요.

다 같이① 기준 확인

사진 요소는 배경이 있고 JPG니?

미리캔버스 사진 목록을 보면 배경 없는 것도 섞여 있어요. 그건 "사진"이 아니라 "배경 제거 사진"이에요. 사진은 배경이 있는 것.

다 같이② 프롬프트 3개

수능 관련 디자인허브 "사진" 요소용 미드저니 프롬프트 3개를 추천해 주고, 각각 추천 사유를 말해 줘.

읽기뷰 · 샷 · 앵글 + 조명

뷰어디서 보나 (시점)샷얼마나 담나 (그릇)앵글위아래 높이조명자연광·스튜디오

사진은 원래 작가가 찍는 거예요. 이 네 가지가 들어가야 현장감이 생기고, 없으면 납작한 사진이 돼요.

뷰·샷·앵글과 조명을 고려해서 다시 작성해 줘. 비율도 사진 용도에 맞게 제안해 줘.

수업 결과: 수능 전날 = 오버숄더 뷰, 수능 선물 = 탑뷰 + 자연광, 수능 당일 = 로앵글 다큐 느낌.

다 같이③ 미드저니에서 만들기

  1. Create → 프롬프트 붙여넣기
  2. 비율: 버튼(16:9 등) 또는 막대로
  3. 같은 프롬프트를 Raw 켜고 한 번 더

사진일 때는 Raw가 덜 꾸며져서 더 나을 때가 많아요. 8.2에서는 특히요.

다 같이④ 결과가 별로일 때

  1. Win + Shift + S로 결과 캡처
  2. GPT 채팅창에 붙여넣기 (Ctrl+V) — 3장 정도
  3. 아래 문장 보내기
첨부한 결과는 미리캔버스 디자인허브 요소의 톤앤매너와 전혀 어울리지 않고 상품성이 없어. 조명이 어둡고, 수능이라는 키워드가 드러나지 않아. 수능 시험장 응원이나 수능 공부 파이팅 장면으로, 밝게, 다시 고민해서 기획해 줘. 이미지는 만들지 말고 프롬프트만.

GPT가 답답해서 직접 이미지를 만들려고 하면 "프롬프트만"이라고 다시 말해요.

읽기글자는 넣지 않아요

미드저니 한글은 깨져요

"수능 대박" 같은 글자를 이미지 안에 넣지 마세요. 글자가 필요한 디자인은 쓰는 사람이 미리캔버스에서 올려요. 꼭 글자 이미지가 필요하면 GPT로 옮겨서 만들어요.

STEP 9

올리기 전에 AI에게 검사받기

올리는 건 쉬워요. 그 전 작업이 더 중요해요.

다 같이HD로 받기

  1. 마음에 드는 이미지 클릭
  2. 가능하면 HD로 만든 뒤 내려받기 — 일반은 픽셀이 모자라요
  3. 파일 속성(마우스 오른쪽 → 속성 → 자세히)에서 가로·세로 픽셀 확인

다 같이GPT 검사

첨부한 사진을 미리캔버스 디자인허브 "사진" 요소로 올리려고 해. 해상도, DPI, 비율, 손·얼굴 왜곡, 글자·상표 노출, 배경 기준에서 업로드에 적합한지 검토하고 고칠 점을 보고해 줘.

답이 엉뚱하면 그 이미지는 폐기하고 다시 만들어요.

읽기DPI는 미드저니가 안 올려 줘요

미드저니는 픽셀은 키워 주지만(HD·업스케일), DPI 숫자는 바꾸지 않아요. 저장할 때 숫자만 바꿔 주면 되는데, 다음 시간에 포토피아(무료 웹 편집기)로 가볍게 바꿉니다.

미드저니의 강점 — 사람 얼굴이 매번 달라요. GPT나 나노바나나는 학습이 잘된 만큼 얼굴이 비슷비슷하게 나와요. 남과 겹치지 않는 결과는 심사에 유리해요.

확인퀴즈

1. 버전 8에서 옴니 레퍼런스 역할을 하는 기능은?

첨부한 대상을 유지한 채 새 장면에 넣어 줘요.

2. 만화·일러스트 느낌을 프롬프트 없이 쉽게 낼 수 있는 모델은?

니지는 일러스트·애니 톤에 강해요.

3. 사진에 현장감을 주는 네 가지가 아닌 것은?

뷰·샷·앵글·조명. 글자는 넣지 않아요.

4. GPT 업무 프로젝트를 만들 때 고를 메모리는?

내 일반 대화 취향이 업무에 섞이지 않게요. 처음에만 고를 수 있어요.
