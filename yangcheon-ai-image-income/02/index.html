그다음에 만듭니다.

판매처 미리캔버스 디자인허브에 가입하고 등록 기준을 읽은 뒤, 미드저니에서 나만의 화풍 장치(프로필·무드보드)를 만들어요.

읽기2차시 녹화 영상

[현장강의] 디자인허브 요소 제작 준비 — 가입부터 프로필·무드보드까지유튜브에서 보기 ↗

영상이 재생되지 않으면 "유튜브에서 보기"를 눌러 주세요. 복습할 때는 교안의 STEP 순서대로 영상을 따라가면 돼요.

읽기우리 과정 전체 지도

1미드저니 기초구독·둘러보기·설정
2판매처·화풍디자인허브·프로필·무드보드
3참조·AI 도우미Attach to Prompt·GPT 프로젝트
4첫 업로드패턴 학습·규격·심사 제출
5규격 보정레퍼런스 묶음·16:9·배경 제거 예고
6PNG 요소배경 제거·스티커 화풍

읽기오늘의 흐름

  1. 판매처 가입 — 디자인허브 기여자
  2. 요소란? — 템플릿을 뜯어 보기
  3. 등록 규격 — 사진 / 배경 제거 사진
  4. AI 제작 도우미 — 가이드를 AI에게
  5. 프로필 — 내 취향 고르기
  6. 무드보드 — 같은 화풍 모으기
  7. 시즌 소재로 비교

확인준비물

STEP 1

미리캔버스 디자인허브 가입

우리가 만든 이미지 요소를 등록하고 파는 "기여자" 페이지예요.

다 같이기여자 가입 순서

  1. 검색창에 미리캔버스 디자인허브 검색
  2. 기여자 가입 — 닉네임(입력란에 보이는 형식대로), 이메일
  3. 필수 약관 확인 → 가입
  4. 메일함에서 인증 메일 버튼 누르기
  5. 로그인 → 콘텐츠 관리 화면

이메일 인증을 꼭

인증을 안 하면 로그인해도 다음 단계가 막혀요. 지금 쓰는 메일 주소로 가입하세요.

읽기콘텐츠 관리 화면

단일 요소조합 요소

제출 예정 → 심사 대기 → 심사 중 → 승인 / 거부

앞으로 여기서 요소를 올리고 심사 상태를 봐요. 우리 수업은 주로 단일 요소를 올립니다.

STEP 2

요소 = 디자인의 재료

파는 사람이 되기 전에, 사는 사람(디자인하는 사람) 입장에서 먼저 봐요.

다 같이템플릿 뜯어 보기

  1. 미리캔버스에서 템플릿 하나 열기 (예: 채용 포스터)
  2. 인물 그림, 아이콘, 사진을 하나씩 눌러 보기 — 따로 선택되는 것이 하나의 요소
  3. 이 요소가 포스터 안에서 어떤 역할을 하는지 말해 보기

다 같이빈 페이지에서 찾아보기

  1. 새 디자인 → 빈 페이지
  2. 왼쪽 요소에서 같은 주제로 사진과 일러스트를 번갈아 넣어 보기
  3. 같은 주제라도 전하는 느낌이 어떻게 다른지 비교

읽기잘 팔리는 요소의 조건

좋은 요소

  • 주제와 구도가 분명
  • 다른 디자인에 넣기 편함 (단순한 배경)
  • 글자·로고·상표가 없음

아쉬운 요소

  • 무엇을 찍었는지 애매
  • 배경이 복잡해서 다른 디자인과 안 어울림
  • 깨진 글자, 상표 노출
STEP 3

등록 규격 읽기

만들기 전에 기준을 알아야 다시 만드는 일이 줄어요.

다 같이유형별로 다른 파일

유형파일핵심
사진JPG배경이 있는 사진. 최소 해상도 120 DPI + 가로·세로 픽셀 기준
배경 제거 사진PNG배경 없이 대상(오브젝트)만. 다른 디자인 위에 얹어 쓰는 용도
그 밖의 유형-가이드의 "자세히 보기"에서 하나씩 확인

제출 대기는 최대 20개

심사가 빠지지 않으면 더 못 올려요. 한 번에 몰아 올리지 말고 조금씩 올려요.

숫자 기준은 바뀔 수 있어요. 올리기 전에 업로드 화면의 안내와 가이드 원문을 다시 확인하세요.

다 같이디자인허브 가이드 열기

  1. 업로드 화면 → 가이드 자세히 보기
  2. 슬래시페이지로 된 가이드가 열려요
  3. "등록 전에 알아야 할 내용", "AI 요소 유의사항", "제출할 수 없는 사례" 읽기

읽기제출할 수 없는 사례

  • 깨짐(글리치), 왜곡된 손·얼굴
  • 부적절한 내용
  • 글자·로고·상표가 들어간 이미지
  • 유형에 맞지 않는 이미지 (예: 사진 유형인데 배경이 없음)
STEP 4

긴 가이드를 AI에게 맡기기

가이드를 다 외우지 않고, AI에게 넣어 두고 질문하며 써요.

다 같이제미나이 노트북 만들기

  1. 제미나이 → 노트북 새로 만들기
  2. 이름: 미리캔버스 디자인허브 제작 도우미
  3. 소스 추가: 디자인허브 가이드 주소
  4. 소스가 들어갔는지 확인

읽기질문은 구체적으로

막연히 "알려 줘" 대신 무엇을 만들고 어디에 쓸지를 함께 적어요.

다음 시간에 알게 된 점

이 노트북은 가이드의 첫 페이지만 읽고 나머지는 자기 지식으로 답한 경우가 있었어요. 그래서 3차시부터는 GPT 프로젝트로 도우미를 다시 만듭니다. 답은 항상 가이드 원문과 대조하세요.

다 같이질문 두 개

질문 1 제작 기준

나는 미드저니로 미리캔버스 디자인허브에 올릴 "사진" 유형 요소를 만들 거야. 소스의 가이드를 근거로 아래를 정리해 줘. 1. 사진 요소의 파일 형식·해상도·크기 기준 2. 심사에서 자주 거절되는 경우 3. 미드저니 프롬프트를 쓸 때 주의할 점 (배경, 글자, 로고, 비율) 각 항목 끝에 근거가 된 가이드 문장을 붙여 줘.

질문 2 무엇을 만들까

한국에서 11월에 디자인 수요가 많은 행사·시즌을 골라, 디자인허브 "사진" 요소로 만들 소재 3가지를 추천해 줘. 조건: 대상 국가 한국 / 사용 시기 11월 / 용도 포스터·카드뉴스·현수막의 사진 재료 각 소재마다 ① 어떤 물건과 장면으로 표현할지 ② 구도 ③ 미드저니용 영문 프롬프트(Korean 포함, 글자·로고 없음)를 적어 줘.

수업에서는 수능 응원 선물, 초콜릿 스틱, 김치(김장) 소재가 나왔어요. 첫 답이 원하는 방향과 다르면 조건을 바꿔 다시 물어보세요.

STEP 5

프로필 — 내 취향을 알려 주기

미드저니에는 화풍에 관여하는 장치가 두 개 있어요. 먼저 차이부터.

읽기프로필 vs 무드보드

프로필 (Profile)

  • 미드저니가 보여 주는 이미지 중에서 고르기
  • 고를수록 내 취향이 쌓임
  • 열어야(활성화해야) 쓸 수 있음

무드보드 (Moodboard)

  • 참고할 이미지를 내가 직접 모으기
  • 내가 만든 결과도 넣을 수 있음
  • 특정 화풍을 반복할 때

순서: 프로필로 취향을 찾고 → 그 화풍을 모아 무드보드로 고정해요.

다 같이먼저 둘러보기

  1. Explore에서 추천·인기 목록을 바꿔 가며 보기
  2. 사진풍 / 평면 그림 / 입체 표현을 비교
  3. Organize에서 내가 지난번 만든 것도 열어 보기
  4. 색감·선·질감 중 무엇이 계속 눈에 들어오는지 메모

다 같이V8 프로필 새로 만들기

  1. Personalize → 새 프로필 (V8)
  2. 두 장씩 나오는 이미지 중 마음에 드는 쪽을 계속 고르기 — 주제보다 색감·표현을 보고
  3. 진행 표시가 차면 "프로필을 사용할 수 있다" 안내
  4. 프로필 이름을 알아보기 쉽게 바꾸기
  5. Create에서 프로필을 켜고 생성

설정 기록 습관

결과가 마음에 들면 버전·프로필·비율·Stylize를 적어 두세요. 다음에 똑같이 비교할 수 있어요.

STEP 6

무드보드 — 같은 화풍 모으기

마음에 든 결과 하나를 출발점으로, 비슷한 그림을 늘려서 보드에 담아요.

다 같이재료 늘리기

  1. 프로필로 만든 결과 중 색감·선이 마음에 드는 것 고르기
  2. 마우스를 올려 Vary Subtle / Vary Strong
  3. 원본과 나란히 놓고 "계열이 유지되는지" 보기
  4. 마음에 드는 결과에서 다시 변형 — 반복

모든 결과를 다 넣지 않아요. 원하는 분위기에 맞는 것만.

다 같이보드 만들기

  1. Moodboards → 새 보드
  2. 기존 생성물에서 비슷한 화풍 20~100장 담기
  3. 보드 이름에 색감 + 선 특징 적기 (예: 파스텔 굵은선)
  4. Create에서 무드보드 켜고 생성

한 걸음 더

인물 말고 사물·풍경에도 같은 무드보드를 적용해 보세요. 주제가 달라도 이어지는 표현이 있으면 그게 내 시리즈의 "얼굴"이에요.

STEP 7

기획한 소재를 실제로 만들기

제미나이에서 받은 시즌 소재를 프로필 / 무드보드로 각각 만들어 비교해요.

다 같이같은 소재, 두 가지 화풍 장치

소재 1 수능 응원 선물

a gift box with chocolates and a small cheering card for a Korean high school student before the college entrance exam, on a clean wooden desk, soft natural light, top view, no text, no logo --ar 1:1

소재 2 초콜릿 스틱 데이

a bundle of chocolate-coated biscuit sticks tied with a ribbon, held by a Korean woman's hands, late autumn mood, warm soft light, close-up, plain background, no brand name, no text --ar 1:1

소재 3 김장

freshly made Korean kimchi in a large bowl with napa cabbage, red pepper paste, Korean family kimjang day, bright natural light, medium shot, no text --ar 4:3

각 프롬프트를 ① 프로필 켜고 ② 무드보드 켜고 한 번씩. 버전과 비율은 똑같이 두세요.

확인비교표 채우기

수능 응원 선물

STEP 9

오늘 정리

판매처 가입 → 규격 → AI 도우미 → 화풍 장치 두 개

확인퀴즈

1. 배경이 있는 "사진" 요소의 파일 형식은?

배경 있는 사진은 JPG, 배경 제거 사진은 PNG예요.

2. 내가 직접 모은 이미지로 화풍을 고정하는 장치는?

프로필은 고르기, 무드보드는 모으기예요.

3. 제출 대기에 한 번에 둘 수 있는 최대 개수는?

수업 당일 화면 기준 20개. 조금씩 나눠 올려요.

4. 무드보드 이름에 적어 두면 좋은 것은?

나중에 화풍을 골라 쓸 때 바로 알아볼 수 있어요.
