0-1두 요소, 무엇이 다른가

PNG 요소 완성된 그림입니다. 색이 고정되어 있어서 입체감, 그라데이션, 질감을 마음껏 넣어도 됩니다.

SVG 요소 미리캔버스 사용자가 색을 바꿔 쓰는 그림입니다. 그래서 색 5개 이하, 단순한 면, 150KB 이하로 만듭니다.

꼭 기억같은 그림은 SVG와 PNG 중 하나로만 올릴 수 있습니다. 그래서 오늘은 산타(PNG)와 종(SVG)처럼 처음부터 다른 그림으로 만듭니다.

STEP 1 · PNG 요소

화려하게 만들기

PNG는 색이 고정되는 대신 무엇이든 표현할 수 있습니다. SVG로는 못 하는 입체감과 그라데이션을 일부러 살립니다.

1-1PNG의 무기

  • 3D 점토, 유리, 털실 같은 재질감
  • 빛이 번지는 그라데이션과 광택
  • 수채화, 색연필 같은 붓 터치

이런 그림은 색을 몇 개로 나눌 수가 없어서 SVG로 바꾸면 깨지거나 용량이 터집니다. 그래서 PNG로 냅니다.

1-2다 같이: 3D 산타 만들기

미드저니 · Create
a cute 3D clay Santa Claus character waving one hand, soft gradient lighting, glossy texture, rich warm colors, full body, single character only, centered, isolated on a plain light gray background, no shadow on the ground --ar 1:1 --s 200
뜻: 한 손을 흔드는 귀여운 3D 점토 산타, 부드러운 그라데이션 조명, 광택 질감, 따뜻한 색, 전신, 캐릭터 한 명만, 가운데, 밝은 회색 단색 배경, 바닥 그림자 없음
막힐 때산타가 둘 나오거나 선물 상자가 따로 떨어져 있으면 "피사체 하나" 규칙에 걸립니다. single character only가 들어 있는지 보고 다시 생성합니다.

1-3왜 회색 배경, 왜 그림자 금지

배경 제거 도구는 "피사체와 배경의 경계"를 찾아서 지웁니다. 배경이 한 가지 색이고 바닥 그림자가 없으면 경계가 또렷해서 깔끔하게 빠집니다.

지난 시간 책상이 붙어 있던 그림은 경계가 없어서 지우기 힘들었습니다. 오늘은 처음부터 지우기 쉬운 그림으로 뽑습니다.

쉽게 말하면지우개질 할 그림은 처음부터 배경을 비워서 그립니다.

1-4내 것 하나 더: 프롬프트 바꿔 쓰기

틀: [소재] + [재질·화풍] + [색감] + 뒤쪽 고정 문장

예시 ① 3D 루돌프
a cheerful Rudolph reindeer with a glowing red nose, 3D felt toy style, soft fuzzy texture, cozy warm palette, single character only, centered, isolated on a plain light gray background, no shadow --ar 1:1 --s 200
예시 ② 수채화 트리
a small Christmas tree decorated with gold ornaments, loose watercolor illustration, soft color bleeding, gentle pastel greens, single object only, centered, isolated on a plain light gray background, no shadow --ar 1:1 --s 250
한 걸음 더유리 오너먼트, 털실 장갑, 진저브레드 쿠키처럼 소재를 바꿔 프롬프트를 새로 씁니다. 같은 프롬프트를 여러 번 돌려 비슷한 그림을 대량으로 내면 어뷰징으로 반려됩니다.

1-5시간 되면: 스티커 형태 PNG 요소

테두리가 둘러진 스티커 모양도 PNG 요소로 낼 수 있습니다. 카드, 상세페이지, SNS에 붙이기 좋아서 찾는 사람이 많아요.

흰 테두리는 피하기순백(#FFFFFF)은 미리캔버스 에디터 배경과 같은 색이라 요소 목록에서 테두리가 안 보입니다. 테두리는 크림색이나 연한 색으로 뽑습니다.

STEP 2 · PNG 요소

마감하고 올리기

업스케일 → 배경 제거 → 포토피아 크롭 → 업로드. 지난 시간에 한 번 해본 길이라 오늘은 규격만 정확히 맞춥니다.

▶설명 영상 · PNG 마감 다섯 단계

2-1업스케일

  1. 마음에 드는 1장에 마우스 오른쪽 버튼 → Upscale
  2. Subtle은 그대로 키우고, Creative는 디테일을 더해 키웁니다. 둘 다 괜찮습니다.
  3. 완성되면 다운로드합니다.

2-2배경 제거

  1. 구글에서 어도비 배경 제거 검색 → 무료 도구에 그림을 끌어다 놓기
  2. 깔끔하게 빠졌는지 확인하고 다운로드
막힐 때공용 PC라 다운로드가 막히면 윈도우 사진 앱으로 엽니다. 편집 → 배경 → 제거 → 복사본으로 저장.

2-3포토피아 크롭·크기

  1. 파일 → 열기
  2. 크롭 도구(C)로 산타 몸에 달랑말랑 맞게 자르고 Enter
  3. V를 눌러 이동 도구로 돌아오기
  4. 이미지 → 이미지 크기 → 긴 변 2,000px 정도로 맞추기
  5. 파일 → PSD로 저장 (나중에 고칠 때 쓰는 원본)
  6. 파일 → 내보내기 → PNG
단축키화면 확대·축소는 Alt+휠, 화면 옮기기는 Space를 누른 채 끌기. Ctrl+휠은 브라우저 전체가 커집니다.

2-4몇 px이면 되나

PNG 요소는 그림 종류에 따라 최소 크기가 다릅니다.

  • 아이콘·이모티콘·캐릭터: 최소 700px
  • 그 외 일러스트(풍경, 장식 묶음 등): 최소 1,500px

산타는 캐릭터라 700px이면 통과지만, 쓰는 사람이 크게 쓸 수 있도록 2,000px 정도로 넉넉히 맞춥니다.

2-5디자인허브 업로드: PNG 요소

  1. 디자인허브 → 콘텐츠 업로드 → 단일 업로드
  2. 콘텐츠 타입: PNG 요소 (배경 제거 사진 아님)
  3. 생성형 AI로 만든 콘텐츠 체크
  4. 제목·키워드 입력 (오른쪽 프롬프트로 챗GPT에게)
  5. 승인 요청
챗GPT · 키워드
미리캔버스 디자인허브에 올릴 PNG 요소야.
주제: 한 손을 흔드는 3D 점토 산타 캐릭터.
검색에 걸릴 한국어 키워드 20개를 쉼표로만 나열해 줘.
시즌어 5개, 대상어 5개, 분위기어 5개, 활용처(카드·배너·상세페이지·SNS) 5개.
제목 후보도 3개 줘.
STEP 3 · SVG 요소

단순하게 설계하기

SVG는 미드저니에서 뽑을 때부터 "벡터로 바꾸기 쉬운 그림"으로 뽑아야 합니다. 여기서 성패가 갈립니다.

3-1왜 단순해야 하나

3-2다 같이: 종 아이콘 만들기

미드저니 · Create
flat vector icon of a Christmas bell with a ribbon, simple bold geometric shapes, only 4 solid colors, no gradient, no texture, no shading, no outline stroke, single object, centered, isolated on a plain light gray background --ar 1:1 --raw --s 50
뜻: 리본 달린 크리스마스 종 플랫 벡터 아이콘, 단순하고 굵은 도형, 단색 4개만, 그라데이션·질감·명암·외곽선 없음, 물체 하나, 가운데, 밝은 회색 단색 배경

4장 중에서 아래가 모두 "예"인 그림을 고릅니다.

고른 그림은 Upscale (Subtle) 후 다운로드합니다.

3-5세트로 늘리기

한 걸음 더양말, 별, 지팡이 사탕으로 크리스마스 아이콘 세트를 기획합니다. 소재마다 프롬프트를 새로 쓰고, 색 4개는 같은 계열로 맞추면 세트 느낌이 납니다.

STEP 4 · SVG 요소

잉크스케이프로 벡터 바꾸기

그림(비트맵)을 색깔별 면 조각(벡터)으로 바꿉니다. 메뉴 이름은 잉크스케이프 1.x 한국어 화면 기준입니다.

▶설명 영상 · 비트맵 추적은 색깔별로 오려내기

4-1그림 가져오기

  1. 잉크스케이프 실행 → 새 문서
  2. 파일 → 가져오기(Ctrl+I) → 종 PNG 선택
  3. 가져오기 창은 기본값 그대로 확인

4-2비트맵 추적

  1. 그림을 클릭해 선택
  2. 경로 → 비트맵 추적(Shift+Alt+B)
  3. 다중 스캔 탭 → 탐지 모드 색상
  4. 스캔 수 4~5 (내 그림의 색 수와 맞춤)
  5. 부드럽게, 배경 제거 체크 → 적용
쉽게 말하면색깔마다 테두리를 따서 색종이 조각처럼 오려내는 작업입니다.
「배경 제거」는 흰색만 지우나요?아닙니다. 흰색을 찾아 지우는 기능이 아니라, 추적이 끝난 뒤 맨 아래에 깔린 조각(배경 층)을 지우는 기능입니다. 그래서 오늘처럼 회색 배경이어도 빠집니다. 다만 배경이 얼룩져 여러 색으로 나뉘면 일부가 남을 수 있어요. 남은 조각은 4-3처럼 직접 지웁니다.
그림 속 흰 부분까지 사라질 때스캔은 "그림 전체에서 같은 색"을 한 조각으로 묶습니다. 배경이 흰색이면 산타 수염·눈·반짝이 같은 흰 부분도 배경과 같은 조각이 되어 배경과 함께 지워집니다. 그래서 SVG용 그림은 회색 배경으로 뽑고, 그림 속 밝은 색은 크림색으로 둡니다. 스캔 수가 너무 적어도 연한 색이 배경색에 합쳐지니 스캔 수는 "그림 색 수 + 배경 1"로 맞춥니다.

4-3원본 치우기

추적한 결과는 원본 그림 바로 위에 겹쳐서 생깁니다.

  1. 맨 위 그림을 옆으로 끌어냅니다. 이것이 새로 만든 벡터입니다.
  2. 제자리에 남은 원본 그림을 클릭 → Delete
  3. 회색 배경 조각이 남아 있으면 클릭 → Delete
막힐 때어느 것이 원본인지 모르겠으면 클릭한 뒤 화면 아래 상태 표시줄을 봅니다. "이미지"라고 뜨면 원본, "그룹"이나 "경로"면 새로 만든 벡터입니다.

4-4조각이 너무 많을 때

확대해 봤을 때 작은 부스러기 조각이 많으면 용량이 커집니다.

  • 추적을 지우고 스캔 수를 줄여 다시 추적
  • 그래도 많으면 STEP 3으로 돌아가 더 단순한 그림을 다시 뽑기
한 걸음 더부스러기 조각만 골라 지워도 됩니다. 노드 도구(N)로 모양이 뭉개진 곳을 다듬어 봅니다.
STEP 5 · SVG 요소

규칙 맞추기

색 정리 → 크랙 받침 → 그룹·크롭·저장 → evenodd 확인 → 용량 확인. 디자인허브 SVG 가이드의 순서 그대로입니다.

▶설명 영상 · SVG 규칙 여섯 가지

5-1색상 정리: 5개 이하

  1. 벡터 선택 → 그룹 해제(Shift+Ctrl+G)
  2. 비슷한 색 조각들을 Shift+클릭으로 함께 선택
  3. 채우기와 선(Shift+Ctrl+F)에서 같은 색 코드로 통일
  4. 흰색 조각은 아이보리(#FAF6EE)로 바꾸기
한 걸음 더그림자는 검정 #000000 + 불투명도 20~30%, 반짝이는 흰색 #FFFFFF + 불투명도로 만듭니다. 업로드할 때 이 두 색을 색상 잠금 하면 사용자가 바꿀 색이 줄어 쓰기 편해집니다.

  1. 전체 선택(Ctrl+A) → 복제(Ctrl+D)
  2. 경로 → 합치기(Ctrl++) → 한 덩어리
  3. End 키로 맨 뒤로 보내기

5-3그룹·크롭·저장

  1. 전체 선택 → 그룹(Ctrl+G)
  2. 페이지를 그림 크기에 맞춤(Shift+Ctrl+R) — 이것이 SVG의 크롭입니다
  3. 파일 → 다른 이름으로 저장 → 형식 최적화된 SVG (Optimized SVG) → 저장
  4. 옵션 창이 뜨면 아래 표대로 확인하고 확인

일반 SVG와 차이둘 다 업로드할 수 있습니다. 최적화된 SVG가 더 가벼워서 150KB 맞추기가 쉽습니다. 저장한 뒤 열어서 모양이 그대로인지 꼭 확인하세요. 한국어 메뉴 이름은 잉크스케이프 버전에 따라 조금 다를 수 있습니다.

5-4evenodd 확인 (메모장)

SVG 안에 evenodd라는 채우기 규칙이 있으면 인쇄 변환에서 문제가 생겨 업로드가 제한됩니다. 잉크스케이프 추적 결과에 자주 들어가니 꼭 확인합니다.

  1. 저장한 SVG에 오른쪽 클릭 → 연결 프로그램 → 메모장
  2. Ctrl+F → evenodd 검색
  3. 없으면 끝. 있으면 fill-rule:evenodd; 또는 fill-rule="evenodd" 문구를 통째로 지우고 저장
  4. SVG를 다시 열어 모양이 원본과 같은지 확인
막힐 때지웠더니 가운데 구멍(리본 고리 등)이 색으로 메워졌다면, 지우기 전 파일로 되돌리고 강사를 불러 주세요. 안쪽 경로 방향을 뒤집는 작업이 필요합니다.

5-5용량 확인: 150KB 이하

  1. SVG 파일에 오른쪽 클릭 → 속성 → 크기 확인
  2. 150KB를 넘으면 잉크스케이프로 돌아가 전체 선택 → 경로 → 단순화(Ctrl+L) → 다시 저장
  3. 그래도 넘으면 스캔 수를 줄여 다시 추적합니다.
끝까지 안 되면그 그림은 PNG 요소로만 냅니다. 같은 그림을 SVG와 PNG로 둘 다 올릴 수는 없습니다.
