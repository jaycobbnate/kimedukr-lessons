STEP 1

채팅으로 다 되는데, 왜 코드를 쓸까요?

오늘 수업은 이 질문 하나에 답하는 시간이에요.

①바이브 코딩이란

바이브 코딩(Vibe coding)은 코드를 직접 치지 않고, 만들고 싶은 것을 말로 설명해서 AI가 만들게 하는 방식이에요. 개발자든 아니든 이제는 말로 만드는 시대예요.

코드는 '개발'과 같은 말이 아니에요.
코드는 채팅창과 다른, AI와 소통하는 또 하나의 공간이에요.

그럼 사람은 무엇을 할까요? 무엇을 만들지 정하고(설계), 일을 나눠 맡기고(지시), 결과를 확인하는 사람이 돼요. 오늘부터 여러분은 AI 직원을 둔 팀장이에요.

②전화로 묻는 전문가 vs 사무실에 출근한 직원

웹 채팅앱의 코드
결과물이 있는 곳대화창 안 (내가 내려받아야 함)내 폴더에 진짜 파일로 쌓임
실행코드를 보여 주거나 대화창 안에서만내 컴퓨터에서 직접 실행하고 확인하고 고침
이어서 일하기다음에는 파일을 다시 올려야 함폴더의 파일을 읽고 이어서 일함
동시에창 하나에서 답을 기다림여러 세션(작업 창)에 나눠 맡김
큰 일파일 몇 개 수준폴더 안 파일 수십·수백 개도 한 번에
인터넷에 올리기안 됨깃허브·버셀로 내 주소까지
채팅이 필요 없어지나요?

아니에요. 묻고, 아이디어 내고, 글 다듬는 건 채팅이 더 편해요. 생각은 채팅, 일은 코드로 나눠 쓰면 돼요.

③8주 동안 만들 것

매주 작품 하나를 완성해요. 4주차부터 만든 작품은 전부 내 홈페이지에 쌓여서, 마지막 날에는 8주 작품이 걸린 내 홈페이지 주소가 남아요.

STEP 2

작업대 준비: 앱 설치와 화면 익히기

AI 직원이 일할 작업대를 내 컴퓨터에 차리고, 실습자료를 받아요.

①오늘 쓰는 세 곳: 위치 표시 읽는 법

이 교안의 회색 지시문 상자 위에는 어디에 보내는지가 표시돼 있어요. 표시대로 그 화면에 붙여 넣으면 돼요.

웹 · claude.ai

크롬 브라우저에서 claude.ai 에 접속한 화면이에요. 설치가 필요 없어요.

앱 · 💬 채팅

클로드 데스크톱 앱에서 왼쪽 위 말풍선 버튼을 누른 화면이에요.

앱 · </> 코드

클로드 데스크톱 앱에서 왼쪽 위 </> 버튼을 누른 화면이에요. 오늘 주로 쓰는 곳이에요.

코드 화면에서는 함께 붙은 표시도 맞춰 주세요. 환경: 이 컴퓨터 폴더: 실습자료 세션 A 처럼 어떤 환경, 어떤 폴더, 몇 번째 작업 창인지 알려 줘요.

⏱ 약 1~2분 표시는 AI가 일하는 데 걸리는 대략적인 시간이에요

코드는 채팅처럼 바로 답이 나오지 않아요. AI가 계획을 세우고, 파일을 만들고, 실행해 보고, 고치는 과정을 거치기 때문이에요. 컴퓨터 성능, 사용량, 일의 크기에 따라 더 걸릴 수 있어요. 기다리는 동안 화면에 지나가는 과정을 읽어 보세요. AI가 무엇을 하는지 보는 것도 공부예요. 오래 걸리는 일은 STEP 7처럼 다른 세션에 다음 일을 맡겨 두면 기다리는 시간이 줄어요.

②시작 전에 확인할 것

  • 클로드 프로(Pro) 이상 유료 구독 (무료 플랜에는 코드가 없어요)
  • 크롬 브라우저
  • 윈도우 또는 맥 컴퓨터
  • 실습자료 (바로 아래 ③에서 받아요)
추가 사용량은 켜지 마세요

프로 요금제는 채팅·코드를 합쳐 일정 시간마다 쓸 수 있는 양이 정해져 있어요. 다 쓰면 기다리면 다시 채워져요. 설정에서 '추가 사용량'을 켜면 따로 돈이 나가니 수업 중에는 켜지 마세요.

③실습자료 내려받기

가상의 회사 「양천상사」의 연습용 파일 21개(메모, 회의록, 견적서, 매출표, 사진)가 들어 있어요. 개인정보는 없어요.

구글 드라이브에서 받기

  1. 내려받은 실습자료.zip을 바탕화면으로 옮겨요.
  2. 파일을 마우스 오른쪽 버튼으로 누르고 모두 압축 풀기를 눌러요.
  3. 바탕화면에 「실습자료」 폴더가 생기면 준비 끝이에요.

예시: 압축 파일을 오른쪽 클릭하면 나오는 메뉴

버튼을 눌러도 안 받아지면

옆의 구글 드라이브에서 받기를 누르세요. 드라이브 화면이 열리면 오른쪽 위 다운로드(⬇) 버튼을 눌러요. 주소: 구글 드라이브 실습자료

④앱 설치 순서

  1. 이미 앱이 있으면 지우기: 윈도우 설정 → 앱 → Claude → 제거 (대화 기록은 계정에 저장돼 있어서 지워도 없어지지 않아요)
  2. claude.com/download 에서 내 컴퓨터용(윈도우/맥)을 받아 설치
  3. 앱을 열고 프로 계정으로 로그인. "보안을 위해 다시 로그인하세요"라는 줄이 보이면 다시 로그인을 눌러요.
  4. 왼쪽 위 </> 버튼(코드)을 눌러요.
  5. + 새로 만들기 → 환경 이 컴퓨터 → 작업할 폴더 선택에서 바탕화면의 「실습자료」를 고르면 시작 준비 끝이에요.
  6. 혹시 Git을 설치하라는 안내가 나오면 git-scm.com 에서 받아 설치하고(설치 화면은 전부 '다음(Next)'), 클로드 앱을 완전히 껐다가 다시 켜요. 요즘 앱은 대부분 이 단계 없이 바로 돼요.

예시: ① 왼쪽에서 '바탕 화면' → ② 「실습자료」 한 번 클릭 → ③ '폴더 선택'

Git이 뭔가요?

파일이 바뀐 기록을 남겨 주는 무료 도구예요. 요즘 앱은 Git 없이도 코드 세션이 시작돼요. 5주차에 깃허브를 쓸 때 필요하면 그때 설치해도 돼요.

⑤앱 화면 읽기: 채팅과 코드

왼쪽 위의 버튼 두 개로 💬 채팅과 </> 코드를 오가요.

번호이름하는 일
1채팅·코드 전환왼쪽 위 버튼 두 개. 말풍선은 채팅, </>는 코드예요.
2+ 새로 만들기새 세션(AI 직원 한 명의 작업 창)을 열어요. 여러 개를 동시에 열 수 있어요. 열린 세션은 아래 '최근 항목'에 쌓여요.
3환경 선택AI가 일할 컴퓨터예요. 이 컴퓨터를 고르세요. 구름 모양(클라우드, 인터넷 속 컴퓨터)은 나중에 배워요.
4작업할 폴더 선택이 세션이 일할 작업실이에요. AI는 이 폴더 안에서 일해요.
5입력창시킬 일을 적어요. 왼쪽 +로 파일 첨부, 스킬, 커넥터를 붙여요.
6모델AI의 두뇌를 고르는 곳이에요. 기본값 그대로 두면 돼요.
7자동 (권한 모드)AI에게 얼마나 맡길지 정해요. 아래 ⑥을 보세요. 같은 줄 끝의 동그란 고리는 남은 사용량이에요.
8터미널 · 브라우저오른쪽 위 >_는 터미널(글자로 명령하는 창), 🌐는 앱 안 브라우저예요. 오늘은 쓰지 않아요.
일을 시키면 이런 것도 보여요
  • 계획 상자: 대화 맨 아래에 AI가 지금 무엇을 하려는지 순서가 보여요.
  • 허락 요청: 확인이 필요하면 대화 안에 버튼이 나와요.
  • 오른쪽 정보 칸: 환경, 연결된 서비스, 만들어진 결과물, 바뀐 파일 등이 카드로 보여요. 안 보이면 오른쪽 위의 정보 칸 보기 버튼을 누르세요.

버튼 이름과 위치는 앱 버전에 따라 조금 다를 수 있어요.

＋환경 선택 메뉴: 앱과 웹이 달라요

코드에서 환경 선택을 누르면 나오는 메뉴예요. 같은 메뉴인데 앱과 웹(claude.ai/code)이 다르게 보여요.

데스크톱 앱웹 claude.ai/code
이 컴퓨터(로컬)✓ 고를 수 있어요. 오늘 이걸 골라요.✗ '데스크톱 앱 전용'이라 못 골라요
클라우드고를 수 있어요기본값(Default)이에요
내 바탕화면 폴더바로 보여요안 보여요 (깃허브 저장소를 가져와 일해요)
「+ 새 환경」은 누르지 않아도 돼요

누르면 로컬·클라우드·SSH·Remote Control, 네트워크 액세스, 환경 변수 같은 창이 나와요. 개발자가 쓰는 고급 설정이라 이 과정에서는 쓰지 않아요. 실수로 열렸으면 취소나 X를 누르면 아무것도 바뀌지 않아요.

구름 모양 Default로 시작하지 마세요

앱에서도 예전에 클라우드를 썼다면 환경이 구름 모양으로 잡혀 있을 수 있어요. 그러면 바탕화면의 「실습자료」가 안 보여요. 항상 로컬 → 이 컴퓨터에 체크가 있는지 확인하세요.

⑥권한 모드: 얼마나 맡길까

입력창 아래 자동이라고 보이는 곳이에요. 누르면 바꿀 수 있어요.

모드뜻
자동알아서 진행하고, 확인이 필요한 일은 멈춰서 물어봐요. 이 수업은 그대로 둬요.
하나하나 허락바꿀 때마다 허락을 받아요. 천천히 지켜보고 싶을 때 좋아요.
계획 먼저계획만 세워서 보여 줘요. 큰 일을 시키기 전에 좋아요.

예시: 대화 안에 나오는 허락 요청 (문구는 상황마다 달라요)

허락 창이 뜨면

무엇을 하려는지 읽고 허락하세요. 확인하고 허락하는 것이 팀장의 일이에요.

⑦막힐 때

Git을 설치했는데도 안내가 계속 떠요
  1. 클로드 앱을 완전히 끄고 다시 켜기
  2. 그래도 안 되면 컴퓨터 다시 시작
  3. 그래도 안 되면 Git을 지우고 다시 설치
코드 버튼을 누르면 업그레이드하라고 나와요

무료 계정이에요. 프로 구독을 결제한 계정으로 로그인했는지 확인하세요.

환경이 구름 모양(Default)으로 돼 있어요

환경 선택을 눌러 이 컴퓨터로 바꾸세요. 구름은 인터넷 속 컴퓨터라 내 바탕화면 폴더를 못 봐요.

공용 PC에서는

껐다 켜면 바탕화면 파일, 설치한 앱, 로그인이 사라지는 PC가 많아요. 만든 파일은 수업 끝에 USB나 내 구글 드라이브로 옮기고, 다음 시간에 앱이 없으면 STEP 2 순서대로 다시 설치하세요.

설치가 안 돼요 (기관 PC)

공용 PC는 설치가 막혀 있을 수 있어요. 옆 사람 화면을 같이 보고, 집에서 내 컴퓨터로 다시 해 보세요.

⑧편하게 따라 하는 요령

글자를 크게

이 페이지는 위쪽 가 + 버튼으로 키워요. 클로드 앱과 크롬은 Ctrl++로 키우고 Ctrl+−로 줄여요.

창 두 개를 나란히

이 교안 창에서 ⊞ Win+←, 클로드 앱에서 ⊞ Win+→를 누르면 화면이 반씩 나뉘어 보면서 따라 하기 편해요.

타자는 최소로

회색 상자의 복사 버튼을 누르고, 클로드 입력창에서 Ctrl+V로 붙여 넣으면 돼요. 오타 걱정이 없어요.

모르는 화면이 나오면 AI에게

⊞ Win+Shift+S로 화면을 캡처하고, 클로드 입력창에 Ctrl+V로 붙인 뒤 "이 화면에서 뭘 눌러야 해?"라고 물어보세요.

한 단계씩 확인

하나 시키고, 결과를 열어 보고, 다음으로 가요. 마지막 STEP의 체크 목록으로 오늘 한 것을 확인하세요.

잘 된 문장은 모아 두기

잘 통한 프롬프트(AI에게 하는 지시문)는 메모장에 모아 두세요. 다음에 단어만 바꿔 다시 쓰면 돼요.

STEP 3 · 비교 실습 ①

웹 vs 앱: AI가 내 컴퓨터를 볼 수 있나요?

같은 질문을 웹 채팅과 앱 코드에 똑같이 해 봐요.

①웹 채팅에 묻기

크롬에서 claude.ai 를 열고 보내요.

웹 · claude.ai⏱ 약 몇 초

앱 · </> 코드환경: 이 컴퓨터폴더: 실습자료세션 A⏱ 약 30초 안팎

STEP 6 · 무한 확장 ①

스킬: AI에게 업무 매뉴얼을 주기

한 번 가르쳐 두면 매번 설명하지 않아도 돼요.

①스킬이란

스킬(Skill)은 AI에게 주는 업무 매뉴얼이에요. "우리 회사 보고서는 이 순서로, 이 말투로" 같은 규칙을 파일로 적어 두면, AI가 그 일을 할 때마다 꺼내 보고 그대로 해요. 새 직원에게 업무 매뉴얼을 주는 것과 같아요.

이미 들어 있는 스킬도 있어요

앱 채팅 입력창에 /를 치면 쓸 수 있는 스킬 목록이 나와요. 코드 입력창 왼쪽 +에서도 스킬을 붙일 수 있어요.

②스킬 만들기

앱 · </> 코드환경: 이 컴퓨터폴더: 실습자료세션 A⏱ 약 1분 안팎
이렇게 보내세요이 폴더에 「양천상사 보고서」 스킬을 만들어 줘. - 보고서는 항상 제목 → 핵심 요약 3줄 → 표 하나 → 다음 할 일 순서로 쓴다. - 존댓말로, 숫자에는 단위를 붙인다. - 결과는 웹페이지(HTML)로 만들어 열어 준다. 다 만들면 스킬 파일이 어디에 있는지 알려 줘.

③새 세션에서 스킬 써 보기

+ 새로 만들기로 새 세션을 열고, 환경 이 컴퓨터, 폴더 「실습자료」를 다시 골라서 보내요. 새 직원도 매뉴얼을 보고 똑같이 일하는지 확인하는 거예요.

앱 · </> 코드환경: 이 컴퓨터폴더: 실습자료세션 B (새로)⏱ 약 1~2분
이렇게 보내세요「양천상사 보고서」 스킬로 10월매출.csv를 보고서로 만들어 줘.

설명하지 않았는데도 정해 둔 순서와 말투로 나와요. 「실습자료」를 정리했다면 10월매출.csv는 「표」 폴더 안에 있어요. AI가 알아서 찾아요.

＋스킬로 만든 보고서는 이렇게 나와요

예시: 스킬에 적어 둔 순서(제목 → 요약 3줄 → 표 → 다음 할 일) 그대로 나와요. 숫자는 실습자료에 따라 달라요.

스킬을 못 찾는다고 해요

폴더가 스킬을 만든 그 「실습자료」인지 확인하세요. 그래도 안 되면 "이 폴더의 .claude 안에 있는 양천상사 보고서 스킬을 읽고 그대로 해 줘"라고 말해 보세요.

③기다리지 말고 바로 세션 B에

④나눠 맡길 때 규칙 두 가지

  1. 세션마다 다른 파일을 맡겨요. 같은 파일을 두 세션이 동시에 고치면 꼬여요. 그래서 파일 이름을 정해 줬어요.
  2. 동시에 최대 2개. 많이 돌리면 사용량이 빨리 닳아요.
두 세션을 나란히 보기

STEP 8

이제 코드의 시대: 같은 엔진, 다른 운전석

오늘 쓴 클로드 코드는 여러 곳에서 똑같이 돌아가요.

①클로드 코드를 쓸 수 있는 곳

개발자는 터미널(CLI, 마우스 없이 글자로 명령하는 창)이나 VS Code에서, 우리는 데스크톱 앱에서 써요. 운전석만 다르고 엔진은 같아요. 앱에서 익힌 시키는 법은 어디서나 그대로 통해요. 코드 화면 오른쪽 위의 >_ 버튼이 바로 앱 안의 터미널이에요.

다른 회사도 같은 방향

오픈AI는 코덱스(Codex), 구글은 제미나이 CLI와 안티그래비티(Antigravity)를 내놨어요. AI 회사들이 모두 "대화하는 AI"에서 "일을 맡기는 AI"로 가고 있어요.

②더 확장하는 방법

  • 스킬: 업무 매뉴얼 (오늘 해 봤어요)
  • 커넥터: 구글 드라이브·지메일·깃허브 같은 서비스에 들어가는 출입증
  • 깃허브: 작업 보관 창고이자 인터넷으로 나가는 문 (5주차)
  • 클라우드 세션: 내 컴퓨터를 꺼도 인터넷 속 컴퓨터에서 계속 일해요

③요금과 사용량

  • 클로드 코드는 프로 이상 유료 구독에서만 돼요.
  • 채팅이든 코드든, 내 컴퓨터든 클라우드든 같은 사용량 주머니에서 나가요. 따로 돈이 더 빠지지 않아요.
  • 코드 작업은 채팅보다 사용량이 빨리 닳아요. 입력창 아래 동그란 고리로 남은 양을 볼 수 있어요.
  • 다 쓰면 보낸 메시지는 기다렸다가, 몇 시간 뒤 사용량이 다시 채워지면 이어서 처리돼요.
  • '추가 사용량'을 켜면 그때부터는 따로 돈이 나가요.
STEP 9

직접 만들기: 로또 · 보고서 · 발표자료

결과물마다 "왜 코드인가"를 하나씩 확인해요. 시간이 모자라면 다음 주에 이어서 해요.

①준비: 폴더 두 개, 세션 두 개

바탕화면에 「바이브코딩」 폴더를 만들고, 그 안에 「로또」와 「보고서」 폴더를 만들어요. 세션마다 자기 폴더에서만 일하게 하려는 거예요.

②세션 A: 로또 웹페이지

+ 새로 만들기 → 환경 이 컴퓨터 → 폴더 「바이브코딩」 안의 「로또」

앱 · </> 코드환경: 이 컴퓨터폴더: 바이브코딩/로또세션 A⏱ 약 1~2분
이렇게 보내세요로또 번호를 뽑는 웹페이지를 만들어 줘. 버튼을 누르면 1~45 중에서 겹치지 않게 6개를 뽑아 작은 수부터 보여 주고, 번호마다 색깔 있는 공 모양으로 보여 줘. lotto.html로 저장하고 열어 줘.

AI가 계획 → 코드 작성 → 파일 저장 → 열기까지 해요. 「로또」 폴더를 열면 lotto.html이 진짜로 있어요.

"한 번에 5세트를 뽑고, 뽑은 기록이 아래에 쌓이게 바꿔 줘." · "휴대폰 화면에도 맞게 바꿔 줘."

③세션 B: 업무 보고서 (A와 동시에)

A가 일하는 동안 + 새로 만들기 → 환경 이 컴퓨터 → 폴더 「바이브코딩」 안의 「보고서」

앱 · </> 코드환경: 이 컴퓨터폴더: 바이브코딩/보고서세션 B⏱ 약 2~5분
이렇게 보내세요가상의 회사 「양천상사」 영업팀의 11월 업무 보고서를 워드 파일(docx)로 만들어 줘. 제목, 이번 달 실적 요약, 팀원 4명의 실적 표(숫자는 지어내서), 다음 달 계획을 넣어 줘. 다 만들면 파일이 어디에 저장됐는지 알려 줘.
워드 파일이 오래 걸리거나 막히면

워드·PPT 파일을 만들 때 AI가 파이썬 같은 도구를 설치하려고 할 수 있어요. 기관 PC에서는 막힐 수 있으니 이렇게 바꿔 말하세요.
"워드 대신 같은 내용을 인쇄하기 좋은 웹페이지 보고서로 만들어 줘."

또는 앱 · 💬 채팅에서 「프로젝트 또는 폴더」로 「보고서」 폴더를 연결하고, 입력창에 /docx를 쳐서 워드 스킬로 만들어도 돼요. PPT는 /pptx예요.

④세션 B: 발표자료 5장 (이어서)

앱 · </> 코드환경: 이 컴퓨터폴더: 바이브코딩/보고서세션 B · 이어서⏱ 약 2~5분
이렇게 보내세요방금 만든 보고서를 바탕으로 발표자료 5장을 PPT 파일(pptx)로 만들어 줘. 1장 표지, 2장 요약, 3장 실적 표, 4장 문제점, 5장 다음 달 계획.

파일을 다시 올리지 않았는데 보고서를 읽고 이어서 만들어요. 앞 결과가 다음 일의 재료가 돼요.

PPT가 막히면

"PPT 대신 화살표로 넘기는 웹페이지 슬라이드 5장으로 만들어 줘."

⑤팀장의 확인

  1. 결과물을 직접 열어 봐요.
  2. 틀린 곳이나 마음에 안 드는 곳 하나를 골라 말로 고치게 해요.
앱 · </> 코드폴더: 바이브코딩/보고서세션 B⏱ 약 1분 안팎
예시발표자료 3장의 숫자가 보고서와 같은지 확인하고, 다르면 보고서 기준으로 맞춰 줘.

AI가 만든 걸 그대로 믿지 않고 확인하는 것,
그게 바이브 코딩에서 사람이 하는 일이에요.
