# kimedukr-lessons

김에듀(kimedu.kr) 수업 교안을 올려 두는 저장소입니다.
구글 사이트에는 교안 코드를 붙여 넣지 않고, 여기 올린 교안의 **주소만** 넣습니다.

## 왜 이렇게 하나요

- 구글 사이트는 사이트 하나에 4,000만 자까지만 넣을 수 있습니다.
- 교안을 「코드 삽입」으로 넣으면 교안 안의 사진까지 전부 글자로 세어집니다. (교안 한 편 = 수십만 자)
- 교안을 여기 올리고 주소로 넣으면, 구글 사이트에는 주소 한 줄(약 300자)만 남습니다.

| | 코드 삽입 (예전) | 주소 삽입 (지금) |
|---|---|---|
| 바이브 코딩 4차시 | 730,164자 | 약 300자 |

## 폴더 구조

```
kimedukr-lessons/
├─ README.md
├─ yangcheon-vibe-coding/        ← 과정 하나 = 폴더 하나 (영문 소문자, 하이픈)
│  ├─ 04/                        ← 차시 = 두 자리 숫자
│  │  ├─ index.html              ← 교안 본문 (사진은 넣지 않고 파일 이름으로 연결)
│  │  ├─ img01.jpg
│  │  └─ img02.jpg …
│  └─ 05/
└─ (다른 과정 폴더)
```

## 교안 주소 규칙

```
https://jaycobbnate.github.io/kimedukr-lessons/<과정 폴더>/<차시>/
```

예) https://jaycobbnate.github.io/kimedukr-lessons/yangcheon-vibe-coding/04/

## 구글 사이트에 넣는 법

1. 오른쪽 「페이지」 탭 → 아래 + 버튼 → **전체 페이지 삽입**
2. 페이지 이름 입력 → 완료
3. **삽입 추가** → **URL 사용** → 교안 주소 붙여 넣기 → 삽입

## 교안을 고칠 때

- 이 저장소에서 해당 폴더의 index.html(또는 사진)만 바꾸면 됩니다.
- 1~2분 뒤 구글 사이트에도 자동으로 반영됩니다. 사이트에서 다시 넣을 필요가 없습니다.

## 주의

- 공개 저장소입니다. 수강생 개인정보·비공개 자료는 올리지 않습니다.
