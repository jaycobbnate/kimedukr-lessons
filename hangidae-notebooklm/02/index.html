③ 질문 두 개 던지기 📖 교재 p27·31

프롬프트 1
이 문서가 어떤 문서인지 한 문단으로 쉽게 설명해줘.
프롬프트 2
이 훈련기준의 능력단위를 코드와 함께 표로 정리해줘.
능력단위란? NCS에서 하나의 일 덩어리. 편성 = 능력단위를 골라서 시간을 나누는 일입니다. 능력단위마다 붙은 코드번호가 오늘 출처 표기의 핵심.
✅ 1단계 성공 기준 — 내 분야 능력단위 표(코드 포함)가 화면에 떠 있다

2단계 채팅 설정 고정 + 능력단위 고르기

① 채팅 설정 템플릿 붙이기 재사용성 15점 📖 교재 3차시

✍️ 프롬프트 엔지니어링 — 좋은 지시문의 4요소
  • 역할 : AI에게 전문가 모자를 씌움 → 답의 수준이 올라감
  • 맥락 : "업로드한 문서만 근거로" → 헛소리 원천 차단
  • 제약 : "없으면 없다고 답해 + 출처 표기" → 검증 가능해짐
  • 형식 : "표로 답해" → 옮겨 담기 편해짐
매번 쓰지 말고 설정에 한 번 고정 — 이후 모든 답에 자동 적용됩니다.

NotebookLM 채팅 설정(맞춤설정) 칸에 아래를 붙여넣으세요.

채팅 설정 템플릿 = 제출물 ②
[역할] 너는 NCS 기반 훈련과정 편성 전문가다. [맥락] 업로드된 NCS 훈련기준 문서만 근거로 답한다. [제약] 문서에 없는 내용은 만들지 말고 "원문에 없음"이라 답한다. 모든 답에 능력단위 코드와 출처를 함께 표기한다. [형식] 표로 정리할 수 있으면 표로 답한다.
이 글을 메모장에도 저장! 오늘 제출물 ②이고, 과목만 바꾸면 계속 재사용하는 자산입니다.

② 능력단위 4개 고르기 📖 교재 2차시

프롬프트 3
초급자 대상 6시간 과정에 적합한 능력단위 4개를 골라줘. 코드와 고른 이유를 한 줄씩 붙여줘.

나온 4개(이름+코드)를 메모지에 적어두세요.

③ 6시간 나누기 📖 교재 4차시

프롬프트 4
고른 능력단위 4개에 총 6시간(50분×6교시)을 배분한 표를 만들어줘. 코드, 시간, 배분 이유 포함.
📊 데이터 리터러시 — AI의 숫자는 내가 검산한다 표의 시간을 직접 더해 합계 6시간인지 확인하세요. AI가 만든 숫자의 오류를 잡아내는 눈이 곧 데이터 리터러시입니다.

① 편성서 4요소 뽑기 완성도 30점 NCS근거 30점 📖 교재 p16·77–80

편성서는 훈련목표 / 훈련내용 / 능력단위 / 훈련시간 4요소. 하나라도 빠지면 감점!

프롬프트 5 · 편성서 본체
지금까지 정한 내용으로 훈련과정 편성서를 작성해줘. 아래 4가지 항목으로 구성하고, 항목마다 근거 능력단위 코드와 원문 출처를 표기해줘. 1. 훈련목표 (2~3줄) 2. 훈련내용 (능력단위별 주요 학습내용) 3. 능력단위 (명칭과 코드) 4. 훈련시간 (능력단위별 배분, 합계 6시간)

② 원문 대조 검증 제출물 ③ 재료 📖 교재 4차시

🔍 HITL 검증 — 사람이 마지막 확인자다 (3동작)
  • ① 출처 클릭 : 답변에 붙은 출처 번호를 눌러 원문 열기
  • ② 원문 대조 : 능력단위 명칭·코드가 원문과 같은지 확인
  • ③ 고치고 기록 : 틀린 곳 수정 + 고친 내용 1~2건 메모
AI는 그럴듯하게 틀립니다. 그리고 AI가 만들어도 최종 책임은 제출하는 나에게 있습니다.
프롬프트 6
편성서의 능력단위 명칭과 코드가 원문과 일치하는지 항목별로 확인하고, 원문 출처를 붙여줘.
🛡️ 윤리 한 줄 — 표현도 점검 AI 결과에 어색하거나 특정 성별·연령에 치우친 표현이 있으면 현업에서 쓰는 중립적 문장으로 다듬으세요. 편향 탐지도 검증의 일부입니다.
성찰 메모 예시(3~5줄): "AI가 능력단위 코드 뒷자리를 틀리게 적어 원문 대조 후 수정함. 다음 ○○과정 편성 때 이 템플릿을 재사용할 계획."
✅ 3단계 성공 기준 — 4요소+출처 있는 편성서 + 고친 오류 메모

4단계 양식에 옮겨 담고 제출

제출 전 자가점검 6개 (= 채점표) 📖 교재 p79

  1. 4요소(훈련목표·훈련내용·능력단위·훈련시간) 모두 있다
  2. 항목마다 출처(능력단위 코드) 표기했다
  3. 출처 링크로 확인 안 되는 내용 0개다
  4. 훈련시간 합계 6시간 맞다
  5. 채팅 설정 템플릿 저장했다
  6. 성찰 메모 3~5줄 썼다

제출 순서 📖 교재 p97

  1. NotebookLM 답변에서 편성서 텍스트 드래그 복사

  3. 템플릿 텍스트 + 성찰 메모 함께 넣기
