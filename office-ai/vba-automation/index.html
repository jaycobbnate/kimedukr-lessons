엑셀 매크로 (VBA) 사용 가이드 

엑셀에서 매크로를 사용하면 반복적인 작업을 자동화할 수 있습니다. 이번 가이드에서는 매크로를 사용하여 작업을 자동으로 기록하고 단축키를 설정해 빠르게 실행하는 방법을 단계별로 설명하겠습니다.

1. 엑셀에서 매크로 사용 준비하기 (개발 도구 탭 활성화)

엑셀에서 매크로를 사용하려면 개발 도구 탭을 먼저 활성화해야 합니다. 이 탭은 기본적으로 숨겨져 있기 때문에 다음 과정을 통해 활성화해야 합니다.

  1. 엑셀 창 상단에서 파일 메뉴를 클릭합니다.
  2. 좌측 하단에 있는 옵션을 클릭합니다.
  3. 나타난 창에서 리본 사용자 지정을 클릭합니다.
  4. 오른쪽 창의 주 탭 목록에서 개발 도구 항목을 찾아 체크합니다.
  5. 확인 버튼을 클릭하면 엑셀 상단에 개발 도구 탭이 표시됩니다.

이제 매크로를 기록하고 관리할 수 있는 개발 도구 탭이 활성화되었습니다.

2. 매크로 기록하기 (단순한 작업 기록 예시)

이제 매크로를 기록하는 방법을 알아보겠습니다. 예를 들어, A1 셀에 "안녕하세요"라는 텍스트를 입력하는 작업을 매크로로 기록해 보겠습니다.

  1. 엑셀 상단의 개발 도구 탭을 클릭합니다.
  2. 코드 그룹에서 매크로 기록 버튼을 클릭합니다.
  3. 나타난 창에서 매크로 이름을 지정합니다 (예: 안녕하세요_입력).단축키 설정: 만약 매크로를 빠르게 실행하고 싶다면 단축키를 지정할 수 있습니다. Ctrl과 함께 사용할 키를 입력합니다. 예를 들어, M을 입력하면 Ctrl + M을 누르면 매크로가 실행됩니다.
  4. 매크로를 저장할 위치를 선택합니다:이 통합 문서: 매크로가 현재 파일에만 저장됩니다.개인용 통합 문서: 엑셀을 열 때마다 사용 가능하며 모든 파일에서 사용할 수 있습니다.새 통합 문서: 새로운 파일에서 매크로를 사용하게 됩니다.
  5. 매크로 설명을 추가할 수 있지만, 생략해도 됩니다. 이후 확인 버튼을 누르면 매크로 기록이 시작됩니다.

매크로 작업 수행

매크로 기록이 시작된 상태에서 엑셀에서 다음 작업을 진행합니다:

  1. A1 셀을 클릭합니다.
  2. "안녕하세요"라는 텍스트를 입력하고 엔터를 누릅니다.
  3. 상단의 개발 도구 탭으로 돌아가서 기록 중지 버튼을 클릭합니다.

이제 방금 수행한 작업(A1 셀에 "안녕하세요" 입력)이 매크로로 기록되었습니다.

3. 매크로 실행하기

매크로가 기록되면 언제든지 해당 작업을 다시 자동으로 실행할 수 있습니다. 매크로를 실행하는 방법은 두 가지가 있습니다: 단축키 또는 매크로 목록에서 직접 실행하는 방법입니다.

1) 매크로 목록에서 실행하기

  1. 상단의 개발 도구 탭을 클릭합니다.
  2. 매크로 버튼을 클릭하여 매크로 목록을 엽니다.
  3. 방금 기록한 매크로(예: 안녕하세요_입력)를 선택하고 실행 버튼을 클릭합니다.

2) 단축키로 실행하기

매크로 기록 시 설정한 단축키(Ctrl + M)를 누르면, 바로 매크로가 실행됩니다. 예를 들어, 매크로가 기록된 상태에서 다른 셀을 선택한 후 Ctrl + M을 누르면, 그 셀에 "안녕하세요"라는 텍스트가 자동으로 입력됩니다.

4. 매크로 편집하기 (기록된 매크로 수정)

기록된 매크로는 VBA(Visual Basic for Applications) 언어로 작성됩니다. 매크로를 조금 더 복잡하게 수정하거나 추가적인 작업을 넣으려면, VBA 편집기를 통해 코드를 수정할 수 있습니다.

  1. 개발 도구 탭에서 매크로 버튼을 클릭합니다.
  2. 편집할 매크로를 선택한 후 편집 버튼을 누르면 VBA 편집기가 열립니다.
  3. VBA 코드가 나타나면, 원하는 작업을 추가하거나 수정할 수 있습니다.예를 들어, "안녕하세요" 대신 "Hello"로 텍스트를 변경하려면, 코드에서 해당 부분을 찾아 수정하면 됩니다.
  4. 편집이 완료되면 저장 버튼을 눌러 변경 사항을 적용합니다.

5. 매크로 보안 설정 (안전한 매크로 사용)

매크로는 엑셀 파일에 악성 코드를 포함할 수 있으므로 보안 설정이 중요합니다. 매크로 실행 전에 보안 설정을 확인하는 것이 좋습니다.

  1. 개발 도구 탭에서 매크로 보안을 클릭합니다.
  2. 나타난 창에서 매크로 설정을 선택할 수 있습니다:모든 매크로 사용 안 함: 매크로 실행이 금지됩니다.서명된 매크로만 사용: 신뢰할 수 있는 서명이 있는 매크로만 실행됩니다.모든 매크로 사용: 모든 매크로를 실행할 수 있습니다 (주의 필요).
  3. 매크로 설정을 적절히 선택한 후 확인 버튼을 누릅니다.

6. 매크로 저장하기 (매크로가 포함된 파일 저장)

매크로가 포함된 엑셀 파일은 매크로 사용 통합 문서 형식으로 저장해야 합니다. 일반 .xlsx 파일 형식으로 저장하면 매크로가 삭제됩니다.

  1. 상단 메뉴에서 파일 > 다른 이름으로 저장을 클릭합니다.
  2. 파일 형식 목록에서 **Excel 매크로 사용 통합 문서 (*.xlsm)**를 선택한 후 저장합니다.

이제 매크로가 포함된 파일로 저장되어 언제든지 매크로를 다시 사용할 수 있습니다.

7. 매크로 삭제하기

필요 없어진 매크로는 삭제할 수 있습니다.

  1. 상단의 개발 도구 탭에서 매크로 버튼을 클릭합니다.
  2. 삭제할 매크로를 선택한 후 삭제 버튼을 클릭합니다.

8. 매크로 활용 예시

자동화 예시

반복적으로 동일한 작업을 매번 손으로 입력하는 대신 매크로를 사용하면 작업이 간단해집니다. 예를 들어, 매일 엑셀에 새로운 날짜를 입력해야 한다면, 매크로를 사용해 자동으로 오늘 날짜를 입력하도록 설정할 수 있습니다.

  1. 매크로를 기록할 때 Ctrl + ; (현재 날짜 입력) 명령을 사용해 기록한 후, 단축키를 설정합니다.
  2. 이후, 단축키만 누르면 자동으로 날짜가 입력됩니다.
