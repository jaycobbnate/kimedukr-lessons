📖오늘의 예시 책 — 「느려도 괜찮아」 6장

모두 896×1200 · 이 순서대로 1쪽~6쪽에 넣습니다.

✓준비물

  • 지난 시간에 만든 그림 6장 (1K · 3:4 = 896×1200)
  • 파일 이름을 01, 02 … 06으로 바꿔 두기
  • 구글 · 네이버 · 카카오 중 쓰시는 계정 하나
  • PC 크롬 권장 (휴대폰도 되지만 화면이 좁아요)

i파일 이름, 왜 바꾸나요?

미리캔버스 업로드 목록은 순서가 섞여 보일 수 있어요. 이름 앞에 번호가 있으면 몇 쪽 그림인지 바로 알 수 있습니다.

예: 01_표지.jpg · 02_등장인물.jpg · … · 06_결승선.jpg

+한 걸음 더 — 6장을 어떻게 나눌까?

플립북은 1쪽(표지)이 혼자 나오고, 그다음부터 두 쪽씩 펼쳐집니다. 6장이면 표지 · 펼침 2개 · 마지막 1쪽 모양이 돼요.

펼침면을 꽉 채우고 싶다면 표지 1 + 본문 4 + 뒤표지 1로 기획해 보세요. 뒤표지에는 "지은이 · 그린이 · 만든 날"을 넣으면 진짜 책 같아집니다.

  3. 쓰시는 계정 버튼 하나 고르기
  4. 계정 창에서 로그인 → 가입 완료

2가입 창에 보이는 버튼

큰 버튼NAVER로 가입
Google로 가입
이메일로 가입
다른 방법카카오 · 페이스북 · 웨일 · 애플 아이콘

!막힐 때

  • 로그인했는데 "새로 가입" 화면이 떠요 → 처음 가입한 버튼이 아닌 다른 버튼을 누른 거예요. 다른 계정 버튼으로 다시 시도하세요.
  • 네이버로 가입했는데 다른 메일 주소가 보여요 → 네이버에 등록된 '연락처 이메일'로 가입되기 때문이에요. 정상입니다.
  • 이메일로 가입했어요 → 메일함의 인증 메일에서 '이메일 인증하기'를 눌러 주세요.

✎꼭 메모해 두세요

"나는 ____ 버튼으로 가입했다."

STEP 2 · 미리캔버스

그림과 똑같은 크기의 캔버스 열기

그림 크기와 캔버스 크기가 같으면 배경으로 넣을 때 하나도 잘리지 않아요.

1캔버스 만들기

  1. 로그인 후 오른쪽 위 새 디자인 만들기
  2. 새 탭에 편집 화면이 열리고 "무엇을 만들어야 하나요?" 창이 떠요
  3. 창 왼쪽 맨 아래 직접 입력
  4. 가로 896 · 세로 1200 · 단위 px
  5. 아래 새 디자인 만들기

✓제대로 됐는지 확인

화면 위쪽 가운데 제목 옆에 896×1200 px 이 보이면 성공입니다.

가로·세로 칸 사이의 자물쇠는 비율 잠금이에요. 숫자를 직접 다 넣을 땐 그대로 두셔도 됩니다.

!막힐 때

  • "무엇을 만들어야 하나요?" 창을 닫아 버렸어요 → 위쪽 크기 표시(1536×2048 px ∨ 같은 글자) 클릭 → 맨 위 직접 입력을 펼쳐 숫자 입력 → 적용
  • 처음 보는 크기로 열렸어요 → 새 디자인은 최근에 썼던 크기로 열릴 수 있어요. 위 방법으로 896×1200으로 바꾸세요.
  • 숫자가 이상하게 바뀌어요 → 칸을 세 번 클릭해 전부 선택한 뒤 다시 입력하세요.

+한 걸음 더 — 왜 896×1200?

오늘 예시 그림(1K · 3:4)의 실제 크기가 896×1200이에요. 정확한 3:4는 900×1200이지만, 그림 크기 그대로 넣는 게 가장 깔끔해요.

다른 크기로 만든 그림이라면 그림 파일의 가로·세로 숫자를 그대로 입력하면 됩니다. (윈도우: 파일 우클릭 → 속성 → 자세히)

STEP 3 · 미리캔버스

그림 6장을 올리고, 한 장씩 배경으로

페이지 6개를 만든 뒤 각 페이지에 그림 한 장씩 꽉 채웁니다.

1그림 올리기

  1. 왼쪽 세로 메뉴에서 업로드
  2. 파란 업로드 버튼
  3. 01~06 그림을 한 번에 선택 (Ctrl 누른 채 클릭, 또는 01 클릭 후 Shift+06 클릭)
  4. 왼쪽 '파일' 목록 맨 앞에 그림이 보이면 완료

2페이지 6개 만들기

  1. 캔버스 아래 + 페이지 추가를 5번
  2. 왼쪽 위 번호가 1 ~ 6까지 생기면 완료

페이지 위쪽 아이콘: ∧∨ 순서 이동 · + 추가 · 복제 · 휴지통 삭제

3그림을 배경으로 — 6번 반복

  1. 1쪽을 클릭해 고르기 (파란 테두리 = 지금 고른 쪽, 그림은 이 쪽에 들어가요)
  2. 왼쪽 목록에서 01 그림 클릭 → 캔버스 가운데 작게 들어와요
  3. 들어온 그림 위에서 마우스 오른쪽 클릭
  4. 메뉴에서 배경으로 만들기 → 페이지에 꽉 차요
  5. 2쪽 ← 02 그림 … 6쪽 ← 06 그림까지 반복

!막힐 때

  • 오른쪽에 "AI 편집 시작하기" 창이 떠요 → X로 닫고 계속하세요.
  • 그림이 작게만 있어요 → 아직 배경이 아니에요. 오른쪽 클릭 → 배경으로 만들기.
  • 엉뚱한 그림을 배경으로 넣었어요 → 배경을 클릭하면 왼쪽에 '사진 배경'이 뜨고, 배경 빼내기로 꺼낼 수 있어요.
  • 쪽 순서가 바뀌었어요 → 페이지 위 ∧∨ 화살표로 옮기세요.
  • 목록에서 내 그림 찾기 어려워요 → 최근에 올린 그림이 맨 앞에 와요. 위쪽 '업로드 검색' 칸에 파일 이름을 넣어도 돼요.
  • 그림이 안 올라가요 → jpg · png만 돼요. webp 파일은 그림판에서 열어 jpg로 다시 저장하세요.

+한 걸음 더

  • 그림을 고른 뒤 B 키 하나면 바로 배경이 돼요.
  • 표지에 제목을 올리고 싶으면 왼쪽 텍스트로 글자를 얹으세요. 배경 위에 떠 있어서 나중에 고치기 쉬워요.
  • 글자가 그림에 묻히면 글자 뒤에 반투명 흰 도형을 깔아 보세요.
STEP 4 · 미리캔버스

슬라이드쇼로 넘겨 보고, PDF로 저장

저장 버튼은 없어요. 작업 내용은 자동으로 저장됩니다.

1슬라이드쇼로 점검

  1. 먼저 1쪽을 클릭 (슬라이드쇼는 지금 고른 쪽부터 시작해요)
  2. 오른쪽 위 ··· → 슬라이드쇼 보기
  3. 키보드 → 다음 쪽 · ← 이전 쪽 · Esc 나오기

2제목 붙이기

위쪽 가운데 "제목을 입력해주세요."를 눌러 책 제목을 적어 두세요.

다운로드 파일 이름과 내 드라이브에서 찾기 쉬워져요.

✓넘겨 보며 3가지만 확인

순서1쪽이 표지, 6쪽이 마지막 장면인가요?
잘림그림이 페이지에 꽉 차고 흰 틈이 없나요?
빈 쪽그림 없는 흰 페이지가 남아 있지 않나요?

3PDF로 내보내기

  1. 오른쪽 위 다운로드
  2. '파일 형식' 칸을 눌러 PDF (웹용) 선택
  3. '페이지 선택'이 모든 페이지 (1~6), '다운로드 정보'가 6 페이지인지 확인
  4. 고해상도 다운로드

!막힐 때

  • 다운로드가 안 돼요 → 주소창 오른쪽의 팝업 차단 표시를 눌러 허용한 뒤 다시 시도하세요.
  • 파일이 어디 갔는지 모르겠어요 → 크롬 오른쪽 위 ⬇ 아이콘, 또는 '다운로드' 폴더를 보세요.
  • 1 페이지로 나와요 → 페이지가 정말 6개인지, 빈 페이지를 지웠는지 확인하세요.

+한 걸음 더 — 웹용과 인쇄용, 뭐가 달라요?

PDF (웹용)문서·화면용. 가볍고 빠르게 올라가요. 플립북엔 이걸로 충분
PDF (인쇄용)벡터를 포함한 인쇄용 파일. 집 프린터로 뽑을 때. 파일이 커요

인쇄용이 안 받아지면 웹용부터 받아 보세요. 그림책처럼 그림만 있는 책은 눈으로 보기에 차이가 거의 없습니다.

STEP 5 · 헤이진 Heyzine

헤이진에 가입하고 PDF 올리기

헤이진은 PDF를 책장 넘기는 온라인 책으로 바꿔 주는 무료 사이트예요. 영어 사이트라 번역부터 켭니다.

가먼저, 한국어로 번역하기

  1. heyzine.com 접속
  2. 화면 빈 곳에서 마우스 오른쪽 클릭
  3. 한국어(으)로 번역

헤이진 언어 메뉴에는 한국어가 없어요. 아래 설명엔 영어 원래 이름도 함께 적었습니다.

1가입하기

  1. 오른쪽 위 Sign Up (가입)
  2. Sign Up with google 에 내 계정이 보이면 클릭
  3. 또는 Email · Password 두 번 입력 → 약관 체크 → Register
  4. Dashboard (내 책장) 화면이 나오면 완료

2PDF 올리기

  1. 위쪽 New flipbook (새 플립북)
  2. "Drag & Drop a File" 창에 PDF를 끌어다 놓거나
  3. Browse File → 다운로드 폴더의 PDF 선택
  4. 변환이 끝나면 책 모양 미리보기가 나와요

!꼭 가입 먼저!

  • 가입하지 않고 첫 화면에서 바로 올린 책은 1주일 뒤 자동 삭제돼요.
  • 가입한 계정의 책은 최소 1년 유지, 계속 보는 사람이 있으면 그대로 남아요.
  • 번역을 켜면 버튼 이름이 우리말로 바뀌어요. 헷갈리면 번역을 끄고 영어 이름을 찾으세요.

  3. 맨 위 칸을 눌러 효과 고르기

⚙같은 창의 설정들

  • 휴대폰으로 볼 가족이 많다면: Magazine + Always single page → 한 장씩 크게 보여요
  • 왼쪽 STYLE의 Background Audio로 잔잔한 배경음, Background로 바탕색도 바꿀 수 있어요
STEP 7 · 헤이진 Heyzine

링크와 QR로 우리 가족에게 보내기

내용을 고쳐도 링크와 QR은 그대로예요. 한 번 보내면 끝입니다.

1링크로 카톡 보내기

  1. 대시보드에서 책 표지 클릭 → Share (공유)
  2. 첫 탭 Link의 Reader link 확인
  3. 아래 Copy link (링크 복사)
  4. 카톡 대화창에 붙여넣기 → 보내기

카드 메뉴의 Copy link를 눌러도 바로 복사돼요.

2QR 코드 받기

  1. Share 창 위쪽 QR code 탭
  2. Download image → 그림 파일로 저장
  3. 출판 책 뒤표지 · 안내문 · 명함에 붙이기

QR 색·로고 바꾸기는 유료 기능이에요.

!관리할 때 주의

  • 무료는 5권까지. 지우려면 카드 메뉴 Delete → 휴지통 → 한 번 더 Delete 해야 완전히 지워져요.
  • 지운 책의 링크는 더 이상 열리지 않아요. 가족에게 보낸 책은 신중하게!
  • 링크를 아는 사람만 볼 수 있어요. 검색으로 남이 찾을 수는 없습니다.

+한 걸음 더 — 5권이 꽉 찼다면

  • 편집 화면의 Replace PDF(링크는 그대로 두고 PDF만 바꾸기)는 유료 플랜 기능이에요.
  • 연습·확인용이라면 로그인 없이: 로그아웃한 상태로 heyzine.com 첫 화면에 PDF를 끌어다 놓으면 5권에 포함되지 않아요. 책 효과 고르기와 링크 공유도 됩니다. 단, 1주일 뒤 자동 삭제되니 가족에게 오래 보여 줄 책은 꼭 내 계정에 올리세요.
