왜 이 수업인가

지금 라임하임어패럴의 상품 등록은 ERP 엑셀을 보면서 카페24 화면에 한 칸씩 손으로 옮기는 일입니다. 상품명을 새로 짓고, 사이즈별로 나뉜 줄을 옵션으로 합치고, 소재 표기를 손님용으로 고치고, 상세페이지 문구와 사이즈표를 쓰고, 홍보 글과 문의 답변까지 따로 씁니다. 상품 하나에 손이 여러 번 갑니다.

오늘은 이 과정 중 "옮기고, 정리하고, 쓰는 일"을 클로드에게 맡기고, 사람은 원본과 맞는지 확인하고 등록 버튼을 누르는 일에 집중하는 방법을 배웁니다.

오늘의 원칙 세 가지

1
원본은 사람이 쥔다가격·소재·치수는 ERP 원본과 실측만 믿습니다. 클로드는 자료가 없으면 그럴듯하게 지어냅니다.
2
규칙은 한 번만 쓴다상품명 짓는 법, 말투, 배송 문구를 프로젝트에 한 번 넣어 두면 누가 시켜도 같은 형식으로 나옵니다.
3
마지막 손은 사람카페24 자동 등록은 별도 개발이 필요합니다. 오늘은 등록 직전까지 준비하고, 등록은 직접 합니다.

클로드 제대로 알고 시작하기

처음이신 분은 여기서 손으로 다섯 번 해 보고 갑니다. 이미 쓰시는 분은 「1 작업방」으로 바로 가셔도 되고, 수업 뒤에 이 페이지로 돌아와 복습하셔도 됩니다.

클로드는 어떤 직원인가

쉽게 말하면클로드는 내가 준 것만 아는, 아주 똑똑한 신입 직원입니다. 우리 회사 사정도, 내 컴퓨터 안도 모릅니다. 대신 자료를 주고 또박또박 시키면 글·표·파일을 빠르게 만들어 줍니다.
그래서이렇게 됩니다
자료를 안 주면그럴듯하게 지어냅니다 (가격·소재·치수까지). 그래서 ERP 원본을 꼭 줍니다.
규칙을 안 정하면매번 다른 형식으로 나옵니다. 그래서 「프로젝트 지침」에 규칙을 넣습니다.
사람이 안 보면틀린 것도 자신 있게 씁니다. 그래서 마지막 확인은 사람이 합니다.

프로젝트(전용 작업방) 화면과 쓰는 법

①프로젝트 안의 입력창 — 여기서 시작한 대화만 지침과 파일이 적용됩니다. 왼쪽 「새 채팅」으로 열면 적용 안 됩니다.
②지침 — 이 방에서 항상 지킬 규칙. 벽에 붙인 사규. 오늘 규칙 문서를 여기 붙입니다.
③파일 — 자주 쓰는 자료 서랍. 올려 두면 매번 첨부 안 해도 됩니다. 사이즈표 형식, 고객응대 모음 등.
④이 프로젝트의 대화 목록 — 상품마다 대화 하나. 나중에 찾기 쉽게 상품번호를 제목에.
  1. 왼쪽 메뉴 「프로젝트」 → 「새 프로젝트」 → 이름 「라임하임 상품등록」
  2. 오른쪽 「지침」 열기 → 규칙 붙여넣기 → 저장
  3. 「파일」에 자주 쓰는 자료 올리기 (오늘은 생략 가능)
  4. 프로젝트 안 입력창에서 새 대화 시작

지침에 붙여넣을 규칙 복사

라임하임 상품등록 규칙너는 라임하임어패럴(여성 의류 쇼핑몰, 카페24 운영)의 상품등록 담당 보조다. 상품 사진과 ERP 엑셀 자료를 받으면 아래 규칙대로 상품정보를 만든다. [반드시 지킬 것] - 가격·소재·혼용률·원산지·세탁방법은 ERP 원본 값만 쓴다. 없으면 지어내지 말고 「확인 필요」라고 쓴다. - 실측(어깨·가슴·총장·허리 등)은 자료에 없으면 숫자를 만들지 말고 빈칸 + 「실측 필요」로 둔다. - 사진에서 보이는 것과 ERP 내용이 다르면 따로 표시한다. - 결과 마지막에 항상 「원본 대조표」(항목 / ERP 원본 / 작성 결과 / 일치 여부)를 붙인다. [상품명] [핵심 특징]+[소재·디테일]+[품목], 25자 이내, 과장 표현 금지, ERP 코드명(end83876, pn, SK, NB, AC 등)은 넣지 않는다. [검색어] 10개 이내, 쉼표 구분, 품목/소재/핏/색상/계절/코디 상황을 고르게. [옵션] 사이즈·컬러별로 나뉜 줄은 상품 1개로 합친다. 표기: 색상{베이지} / 사이즈{S|M|L}. 색상은 한글로. ERP 오타는 바로잡고 대조표에 표시. [소재] 「폴리에스터90,면10,」 → 「폴리에스터 90%, 면 10%」. 겉감·안감 구분. [세탁] 드라이 → 드라이클리닝 권장 / 손세탁 → 찬물 단독 손세탁. [상세페이지 순서] 한 줄 소개 → 포인트 3가지 → 코디 제안 2가지 → 사이즈표 → 소재·세탁 → 배송·교환 안내. [배송·교환 고정 문구] - 결제 확인 후 영업일 기준 2~3일 이내 출고됩니다. - 수령 후 7일 이내 교환·반품 가능하며, 착용·세탁·택 제거 시 불가합니다. - 모니터 환경에 따라 실제 색상과 차이가 있을 수 있습니다. - 실측은 재는 방법에 따라 1~3cm 차이가 있을 수 있습니다. [말투] 30~50대 여성 고객 대상, 차분하고 고급스럽게, 「~해요」체, 이모지 금지.

홍보 글과 고객 응대 문구

같은 상품 정보로 여러 글을 만들고, 프로젝트에 저장해 두고 꺼내 씁니다.

인스타그램 · 블로그 글

홍보 글이 데님 팬츠로 홍보 글을 만들어 줘. 0. 먼저 손님이 검색할 때 잘 걸리도록 상품명과 검색어 10개를 다듬어 줘 (손님이 실제로 치는 말 기준, 바꾼 이유 한 줄씩) 1. 인스타그램: 3줄 이내 + 해시태그 10개 2. 블로그: 제목 3개 + 본문 (가을 코디 2가지 중심, 400자) 3. 이벤트 안내: 신상품 첫 구매 고객 대상 (혜택 칸은 [혜택 입력]으로 비워 두기)

문의 · 교환 · 반품 답변

고객 응대쇼핑몰 고객 게시판 답변 문구를 만들어 줘. 정중하고 짧게. 1. 사이즈 문의: 「키 162cm인데 M 맞을까요?」 (실측이 없으면 실측 확인 후 안내한다고 답하기) 2. 교환 요청: 「사이즈가 작아서 L로 바꾸고 싶어요」 3. 반품 요청: 「색이 화면과 달라요」 규칙의 배송·교환 문구를 기준으로.
저장해 두기마음에 드는 답변은 프로젝트 화면 오른쪽 파일(프로젝트 지식)에 「고객응대 모음」으로 올려 두면 다음에 같은 말투로 만들어 줍니다.

사이드 · 글자가 움직이는 홍보 영상 한 걸음 더

클로드는 영상 파일을 직접 만들지는 못하지만, 글자와 입체 장면이 움직이는 웹페이지는 만듭니다. 그걸 화면 녹화하면 인스타그램 릴스용 영상이 됩니다.

순서할 일
1브랜드 정체성 한 장 만들기 → 프로젝트 「파일」에 저장
2상품 하나로 15초 타이포 모션(글자 애니메이션) 웹페이지 받기 → 내려받아 브라우저로 열기
3화면 녹화 (윈도우: Win+Alt+R, 또는 캡컷 화면 녹화) → 9:16으로 잘라 업로드
① 브랜드 정체성[상황] 나는 라임하임어패럴(30~50대 여성 의류 쇼핑몰) 담당자야. [목적] 앞으로 모든 홍보물에 같은 느낌을 유지하려고 해. [요청] 우리 브랜드 정체성을 한 장으로 정리해 줘: 한 줄 슬로건, 톤(형용사 5개), 메인 색 2개·보조 색 1개(색상 코드), 글꼴 느낌(고딕/명조, 굵기), 쓰는 말투, 쓰지 않는 표현. [조건] 첨부한 상품 사진들의 색감과 분위기를 근거로. 표로 정리.
② 타이포 모션 웹페이지[상황] 위 브랜드 정체성과 「스판 부츠컷 데님 팬츠」 상품정보를 쓸 거야. [목적] 인스타그램 릴스에 올릴 15초 홍보 영상을 화면 녹화로 만들려고 해. [요청] 세로 9:16 화면에서 글자가 순서대로 나타나는 타이포 모션 웹페이지(HTML 파일 하나)를 만들어 줘. 배경은 three.js로 은은하게 움직이는 입체 장면. [조건] 순서: 브랜드명 → 한 줄 카피 → 상품명·소재 → 가격 → NEW ARRIVAL. 브랜드 색 사용, 글자는 크게, 자동 재생, 15초 안에 끝나기, 외부 파일은 three.js 하나만.
예시 보기바로 다음 「★ 홍보 영상 예시」 탭에서 15초 예시 두 가지(글자+입체, 실제 사진)를 재생해 볼 수 있습니다.

자주 묻는 질문

Q. 카페24에 자동으로 올라가게는 안 되나요?
카페24 개발자 연동이 필요한 작업이라 별도 개발이 있어야 합니다. 오늘 방법으로 등록 직전까지 준비 시간을 줄일 수 있습니다.

Q. 무료 계정도 되나요?
프로젝트는 무료 계정도 5개까지 만들 수 있습니다. 다만 사용량이 적어 사진을 많이 넣으면 잠시 막힐 수 있습니다. 여러 상품을 폴더째 처리하는 코워크는 유료(Pro 이상)입니다.

Q. 결과가 매번 조금씩 달라요.
정상입니다. 규칙(지침)을 구체적으로 적을수록 결과가 비슷해집니다. 마음에 드는 결과는 규칙에 예시로 추가해 두세요.
