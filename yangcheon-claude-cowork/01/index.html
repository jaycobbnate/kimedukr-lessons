막힘 사전 — 화면 / 왜 / 뭘 누르나

권한을 허용하겠냐는 창
코워크·코드가 폴더를 읽고 쓰려면 허락이 필요. 허용. 그 폴더만 허용됩니다.
"폴더를 찾을 수 없음 — 이 세션의 작업 폴더가 더 이상 존재하지 않습니다"
세션이 예전 폴더(남의 것, 또는 빠진 USB)에 묶여 있음. 아래 폴더 이름을 눌러 AI오피스로 바꾸거나 새 세션. USB 오피스에서 매주 볼 수 있는 정상 화면.
채팅에서 코워크로 바꾸고 싶은데 안 바뀜
대화는 시작할 때 채팅/코워크가 정해지고 중간에 못 바꿉니다. 새 대화를 여세요.
CLAUDE.md 규칙이 반영 안 됨
① 새 대화였나 ② 폴더 지침이 저장돼 있나 ③ 그래도 안 되면 P4-B("먼저 CLAUDE.md를 읽고,")를 붙여 보내기.
스킬 크리에이터가 "적용" 버튼 없이 파일만 내보냄
정상 경로 중 하나. 설정 → 기능 → 스킬 → 업로드로 직접 올리면 됩니다.
예약 작업이 내 폴더에 저장 안 됨
예약은 클라우드에서 돌아 PC 폴더에 직접 못 씁니다. 결과는 클로드 안에 남고, 5차시에 드라이브 연결로 해결.
코워크가 말한 시간이 9시간 어긋남
서버 시간(UTC). "한국 시간으로"라고 다시 말하기. CLAUDE.md 폴더 규칙에 KST 기준이 들어가 있으면 파일명은 맞습니다.
엑셀(xlsx)이 안 만들어짐
"csv로 만들어줘"로 다시. csv도 엑셀로 열립니다.
CLAUDE.md가 CLAUDE.md.txt로 저장됨
메모장 저장 시 파일 형식을 "모든 파일"로. 이미 됐으면 탐색기에서 이름 바꾸기로 .txt 삭제 (확장자가 안 보이면 보기 → 파일 확장명 체크).
앱에 남의 이름·남의 폴더가 보임
설정 → 계정 → 로그아웃 → 내 계정으로. 남의 폴더는 지우지 말고 무시.
Pro 결제가 안 됨
코워크는 유료. 오늘은 옆자리 화면을 보며 프롬프트를 같이 읽고, 귀가 전 결제하면 집에서 3단계를 그대로 따라 할 수 있습니다.
한도가 다 됐다는 안내
설정 → 사용량에서 확인. 모델을 Sonnet/Haiku로 내리고, Opus는 P3 같은 설계 작업에만.
화면이 교재와 다름
앱이 자주 업데이트됩니다. 이름(채팅·코워크·코드·프로젝트·예약됨·디자인)은 같습니다. 못 찾으면 손.
