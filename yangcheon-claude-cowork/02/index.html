권한을 허용하겠냐는 창
코워크가 폴더를 읽고 쓰려면 허락이 필요합니다. 허용. 그 폴더만 허용됩니다.
"폴더를 찾을 수 없음"
USB가 빠졌거나 드라이브 문자가 바뀐 것. 폴더 이름을 눌러 다시 선택하거나 새 대화를 여세요.
채팅에서 코워크로 못 바꿈
대화는 시작할 때 정해지고 중간에 못 바꿉니다. 새 대화를 여세요.
캔바 연결이 안 됨 / 목록에 없음
계정이 없으면 구글 계정으로 무료 가입하면 됩니다. 그래도 안 되면 옆자리 화면을 같이 보세요 — 5주차에 제대로 합니다.
카드뉴스가 안 만들어짐
"캔바에 프레젠테이션으로 만들어줘"로 바꿔보세요. 그래도 안 되면 넘어갑니다.
스킬 만들기가 안 끝남
정상입니다. 오래 걸립니다. 그 창은 그대로 두고 새 대화를 열어 다음 단계를 진행하세요.
스킬이 만들어졌는데 "적용" 버튼이 없음
오류가 아닙니다. 설정 → 기능 → 스킬 → 업로드로 나온 파일을 직접 올리면 됩니다.
사진이 안 옮겨짐 / 탐색기에 그대로
탐색기에서 F5(새로고침). 그래도 없으면 클로드에게 "어디에 저장했어?"라고 물어보세요.
너무 오래 걸림
50장이면 분석 1~2분, 옮기기 3분 정도가 정상입니다. 화면에 진행 상황이 올라오면 돌아가는 중입니다.
CLAUDE.md 가 CLAUDE.md.txt 로 저장됨
메모장 저장 시 파일 형식을 "모든 파일"로. 이미 그렇게 됐으면 탐색기에서 이름 바꾸기로 .txt 를 지우세요.
CLAUDE.md 규칙이 안 지켜짐
① 새 대화에서 했는지 ② 그래도 안 되면 "이 폴더의 CLAUDE.md를 먼저 읽고," 를 앞에 붙여 보내세요.
내장 브라우저가 안 열림
설정 → Cowork → 기본 브라우저 확인. 아직 안 보이면 순차 적용 중입니다. 없어도 오늘 수업은 다 됩니다.
한도가 다 됐다고 함
설정 → 사용량에서 확인. 자동 승인 모드는 사용량을 더 씁니다.
앱에 남의 이름이 보임
설정 → 계정 → 로그아웃 → 내 계정으로. 다른 반 흔적인 폴더는 지우지 말고 무시하세요.
